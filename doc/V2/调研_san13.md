# 调研：《三国志13》功能结构拆解（策划视角）

> 版本基准：**《三国志13 威力加强版》(PK)**，本篇差异单独标注
> 调研日期：2026-10-02
> 用途：「闲逛」V2 方向评估的输入素材——**只做拆解与归因，不做决策**
> 资料来源：官方系统页、百度百科、Gamersky / 游侠攻略、Steam 中文长评、巴哈姆特心得（见文末来源清单）

---

## 〇、一句话结论（先给判断，后面是证据）

**三国志13 的设计母题是"把战略模拟的视角从『势力』下移到『一个人'"**，为了实现这一点，它把内政与战争都**降维成"任务"**，把腾出来的设计预算全部押在**人的关系与身份跃迁**上。

这带来一个对我们极重要的观察：**它是一台"身份跃迁机器"，不是"数值增长机器"**。它所有的成长反馈（官爵 / 威名 / 绊 / 名声）都是**离散的、有名字的、带叙事的里程碑**，而不是连续爬升的数字。这一点与我们在 V1 文档里自己写下的结论（"纯对数曲线体感是越升越没感觉，需要离散里程碑"）高度吻合。

同时它也暴露了代价：**把内政降维成任务之后，策略深度掉了；把自由交还给玩家之后，节奏碎了；全自动征兵让后期滚雪球。** 这三件事是我们做挂机版时最需要提前防的。

## 一、产品基本盘

| 项 | 值 |
|---|---|
| 本篇发售 | 2016-01-28（PC / PS3 / PS4 / Xbox One），后移植 Switch |
| 威力加强版 | 2017-02-16 |
| 平台形态 | 单机买断，无联网 |
| 系列坐标 | RPG 路线的精神续作——承接 **三国志10**（武将扮演），与 11（箱庭内政）/12（简化快节奏）/14（涂色战略）走不同支线 |
| 规模 | **60 座都市**（系列最多，含交州）+ **140+ 集落**；本篇 **700 名武将**，PK **800 名** |
| 单局时长 | 数十至上百小时（多剧本 / 多可扮演武将重复游玩） |
| 综合口碑 | 约 **7.5 / 10**；"系列最好的角色扮演三国志，但不是最好的战略模拟三国志" |

> **关键规模数字的意义**：60 城 × 140 集落 × 800 人 = 这台机器是靠**内容体量**撑住重复游玩的，不是靠系统深度。这直接对应我们在方向评估里说的风险 #1（内容生产量）。

## 二、设计母题推导出的取舍

从母题"扮演一个人"出发，可以反推出它做过的每一个取舍：

| 母题推论 | 具体取舍 | 副作用 |
|---|---|---|
| 玩家是一个"人"，不是"势力意志" | 内政与军事全部**任务化**（接任务 → 跑腿 → 报告） | 内政深度大幅下降（相对 11 代），被批评"像跑腿" |
| 人的价值由**别人承认** | 成长主反馈不是属性，而是**官爵 / 威名 / 绊 / 名声** | 属性成长被挤压，后期"刷属性"失去挑战 |
| 人应该能选自己的活法 | PK 加**六条威名路线**，在野也能玩 | 自由度过大 → 不同武将只剩初始数值差异 |
| 人的关系要看得见 | **关系相关图**、亲近感、感情状态、绊事件 | 关系建立靠重复送礼/访问，机械感强 |
| 人会被大势裹挟 | 评定 / 使命由君主下达，玩家可能被强制征召 | 玩家"身不由己"，被列为差评主因之一 |

> **这张表是我们做挂机版时的第一道护栏**：我们继承它的成长结构（离散里程碑 + 关系），但要避开的正是"任务化导致深度下降"和"自由度过大导致节奏碎裂"。

## 三、功能结构总图

按"谁的权力 / 谁的成长 / 谁的关系 / 做什么 / 打什么 / 在哪打"分六层。

### 3.1 身份层（决定"我现在能做什么"）

**九品官爵制**：九品 → 一品，共 9 级，由**功绩**驱动。

| 品级 | 身份 | 解锁的权力 |
|---|---|---|
| — | **在野** | 只能行走、访问、结交；在空城"举兵"自立，或"任官"入仕 |
| 九品～八品 | **一般武将** | 提案自己的任务、接受上级指派 |
| **七品** | **重臣** | 可向统治者提案**他人**的任务；内政/军事/军师三类，对应能力 ≥90 可提 2 项 |
| **五品** | **太守** | 统治一座都市，可开都市评定、任命重臣 |
| **二品** | **都督** | 统治一个军团（多座城），可开军团评定 |
| — | **君主** | 统治势力，开势力评定、下达使命 |

> **设计要点**：身份不只是称号，它是**权限解锁器**。每升一级，玩家可操作的指令集合变大。这是"官职"这个成长维度能成立的根本原因——**它给的是新玩法，不是新数字**。

### 3.2 人物层（我是谁）

| 子系统 | 内容 |
|---|---|
| 四维能力 | 统率 / 武力 / 智力 / 政治，上限 100（名品、官爵可突破） |
| **特技** | 大量，通过师事、绊、任务习得；可被传授 |
| **战法** | 战场技能，可学习替换 |
| **价值观** | 才爱（求知）/ 勇爱（勇猛）/ 义理（忠诚）等——影响与同类武将的亲近速度，也决定 AI 行为 |
| **实绩** | 爱勇（单挑胜）/ 爱才（舌战胜）等，随行动增减，是价值观的量化产物 |
| **名声**（PK） | 人脉广度的数据化：**绊武将越多、绊武将自身名声越大、身份越高 → 名声越大**。是威名的必要前置 |
| **威名**（PK） | 对天下公告的自取称号，见 §5.2 |

### 3.3 关系层（我和谁有关系）—— 本作真正的重心

关系是一条**严格的四段式漏斗**：

```
亲近感（数值） → 感情状态（临时 buff） → 绊事件（触发条件） → 绊（永久关系）
```

| 阶段 | 机制 | 关键规则 |
|---|---|---|
| ① **亲近感** | 数值。赠送**符合其嗜好**的名品涨幅更高；协助任务、宴会、介绍信也涨 | 80 点是普通上限；送对礼物是关键 |
| ② **感情状态** | 有**时效**的状态：感谢(30日) / 好感(30日) / 敬畏(条件未满前) / 迷恋(3个月) | 不同状态解锁不同行为：感谢→帮忙、敬畏→可登用/可访问、迷恋→主动来访 |
| ③ **绊事件** | 亲近感满 + 感情状态达标 → 触发委托事件 | **完成委托才成绊** |
| ④ **绊** | 永久关系，分 LV | 一般 LV3；义兄弟/配偶 LV4；特殊绊（如孙策·周瑜"断金之交"、桃园之誓）LV5 |

**绊的功能（它为什么值得玩家去刷）**：

- 习得对方的**传授特技**（成长）
- 任务"协助委托"**必定成功**且成果增加
- 评定时容易赞同你
- 编入同一部队 → 部队变强；附近时战法被强化
- 单挑/舌战中恢复体力或提升能力
- 容易协助你的**叛乱 / 举兵**（终局玩法的关键前置）
- 可编为**同道**共同行动，全体能力按威名系统强化

**关系的外延**：介绍信（结识）、亲笔信（让两个我认识的人互结绊）、宴会、结拜、结婚、生子育儿（4 岁选培育方针，12 岁成人可登用）。

> **对本项目的直接价值**：这条漏斗是"人物互动"从**不可量化的叙事**变成**可挂机、可结算的数值流程**的现成范式。它的每一段都可以单独拿出来做自动化改造（见 §9）。

### 3.4 行动层（我能按哪些按钮）

**都市内**：政厅（提案/报告/评定/举兵/任官）、内政（商业/农业/文化/治安）、军事（训练/兵科/征兵/编制私兵）、人事（登用/搜索/介绍）、计略（笼络/作敌）、外交、酒馆（宴会/编制私兵）、市场（买卖军粮/名品）、自宅（师事/锻炼）。

**战略面**：在 3D 一体化中国地图上移动（都市 / 关卡 / 集落 / 要冲 / 道路），移动本身消耗天数。

**四类任务**（委托）：
| 类型 | 内容 |
|---|---|
| 内政 | 商业/农业/文化/巡查，提升都市数值 |
| 军事 | 训练、征兵、出征、攻略 |
| 人事 | 探索、登用在野武将 |
| 计略·外交 | 笼络、作敌、怀柔部落（140+ 集落）、结盟/停战 |

### 3.5 任务层（三层下达链）

```
评定（开会议定方向）
  └→ 使命（势力级年度目标，5 选 1：打倒势力/攻略都市/充实内政/充实军备/临机应变，360 天内达成）
       └→ 任务（具体活儿；由统治者分配，也可由武将在政厅"提案"争取）
            └→ 命令信（下达任务要消耗一枚；君主/任命武将最多 2 枚，多任命武将可增加）
```

**这条链的设计意图**：让玩家既是"被指挥的人"，又有"争取活儿干"的主动权（提案）。**提案 = 玩家在官僚体系里的主动性出口**，也是功绩的主要来源。

### 3.6 战斗层

| 层 | 内容 |
|---|---|
| 战略 | 多都市可同时派出军势；每军势含若干**部队**（1 主将 + 最多 2 副将）；需配兵粮，每日消耗 |
| 接触 | 两军势在战略地图接触 → 玩家可选择切入指挥，不切入则自动打完 |
| 战场 | 3D 即时策略。分野战 / 攻城战 / 水战（本篇）；PK 战场面积 **×4** |
| **军议**（PK） | 战前会议：总大将任命**参军**，参军提案战术 + 部队配置；参军智力越高越能看破敌方战术；其他武将可反论 → 触发**舌战**，胜方提案被采用 |
| **战术**（PK） | 分**阵 / 诡计 / 兵力**三类，只能在其战术地点发动，有时限与发动时间；如落石、火计、医疗、扰乱、陷阱、行贿。部分为威名专属 |
| **单挑** | 5 回合，攻击/必杀/瓦解/防御 + 心技体量表；相克关系（攻击>瓦解>防御>攻击，必杀>攻击与瓦解、劣于防御）；武力高者先手。战斗中、巡查讨贼、师事切磋均可触发 |
| **舌战** | 5 回合，主张/挑衅/反驳（+大主张等强化版），带天数/学识/道义三属性相克；用于外交、评定、登用、拜师等关键决断 |

> **单挑与舌战的设计定位**：它们是**"个人能力可以直接决定结果"的小舞台**，是"扮演一个人"这个母题在战斗里的落点。对我们而言，这两个小游戏恰恰是**最不适合自动化**的部分（需要实时操作），改造方案见 §9.2。

### 3.7 世界层

60 都市 + 140+ 集落（怀柔后可提供收入与兵种）+ **要冲**（PK，都市间交通要道，可建要塞）+ 关卡 + 一体化 3D 地图（可缩放到都市内部）。

## 四、玩家行为拆解

### 4.1 行为颗粒度

- 时间以**天**为单位流逝，执行任务与地图移动都消耗天数；可快进（3 档速度），达成任务/评定/战斗开始时自动停止。
- 行动受**命令信**约束：下达任务消耗一枚，君主/任命武将最多持 2 枚。
- 具体行动耗时天数、命令信恢复周期等细粒度数值未在可靠资料中确认，⚠ **待复核**。

### 4.2 典型行为清单（按一个月切片）

| 频率 | 行为 | 耗时感 |
|---|---|---|
| 每天 | 在都市地图上跑动（政厅/设施/武将宅之间）、执行当前任务 | 短、碎 |
| 每隔几天 | 访问武将 → 谈话 / 赠送名品 / 师事 / 协助任务 | 短 |
| 每旬 | 报告任务、接新任务或提案任务 | 中 |
| 每月 | 领取俸禄、论功行赏（季度第 1 名是功绩大头） | 短 |
| 不定期 | 出征参战（战场即时指挥 1 场） | 长、整块 |
| 每年 | 评定（选年度使命） | 长 |
| 里程碑 | 升品、换威名、结绊/结拜/结婚、举兵自立 | 长、高情绪 |

### 4.3 行为的四种驱动动机

| 动机 | 玩家在想什么 | 对应系统 |
|---|---|---|
| **任务驱动** | "我这个月要完成使命，拿到功绩" | 评定 / 使命 / 任务 / 命令信 |
| **关系驱动** | "我还差两个人就能凑齐举兵班底" | 亲近感 / 绊 / 同道 |
| **成长驱动** | "我政治还差 10 点才够当内政重臣" | 能力 / 特技 / 师事 |
| **自立驱动** | "什么时候反，反在哪座城" | 举兵 / 叛乱 / 笼络 |

> **观察**：这四种动机在**不同阶段的主导地位是轮替的**（见 §7.2）。这是它节奏设计的骨架，也是我们可以直接借用的东西。

## 五、成长路径（多维棋盘）

### 5.1 六条成长轴

| 轴 | 是什么 | 怎么涨 | 涨了给什么 | 性质 |
|---|---|---|---|---|
| **能力** | 统武智政（≤100） | 各种行动累积经验；**师事**（与指导者差距越大经验越多） | 任务效果、战法威力 | 连续数值 |
| **特技 / 战法** | 具体技能 | 师事习得、**绊武将传授**、事件 | 直接战斗力/内政力 | 离散收集 |
| **功绩** | 业绩点数 | 完成任务、季度论功第 1、达成使命 | → **品级** | 连续 → 离散 |
| **品级（官爵）** | 九品→一品 | 功绩达阈值（3000 可升七品） | → **身份权限**（重臣/太守/都督） | 离散里程碑 |
| **名声** | 人脉广度 | 绊武将数量 × 绊武将名声 × 身份 | → 威名的必要前置 | 复合数值 |
| **威名**（PK） | 对外公告的称号 | 满足**条件 + 名声**双门槛后自选 | → **专属指令**（见下） | 离散 + 分支 |
| **绊 / 关系网** | 与其他武将的关系 | 送礼/协助/事件 | 特技传授、战斗加成、举兵班底 | 网络，不是数轴 |

### 5.2 威名系统（PK 核心，最值得单独看）

**六系统，分两大类**：

| 所属 | 系统 | 擅长 |
|---|---|---|
| 在野 | **侠客** | 募集私兵、增加军粮；上位可**暗杀**武将 |
| 在野 | **商人** | 增加资金军粮、**操纵势力**（资助、煽动战争） |
| 仕官 | **将军** | 募集/锻炼士兵与私兵 |
| 仕官 | **武官** | 锻炼自己与特定武将，切磋提升亲近感 |
| 仕官 | **军师** | 战术强化、登庸武将、提升忠诚；可修复/夺取要冲 |
| 仕官 | **官吏** | 增加资金军粮、外交 |

**关键设计**：
1. **威名 = 自报家门**：玩家主动选，不是被授予 → 主体性来源
2. **上位威名有分歧**：同一系统内不同分支，可玩内容不同（如侠客→义侠烈士 / 云龙风虎 / 贼王 / 暗杀者）
3. **上位威名解锁专属指令**：私兵募集、巡回、掠夺、袭击、暗杀、仲裁、劝诱…
4. **威名绑定"君令"与"战术"**：影响战场可用战术
5. **在野也能玩**：这是 PK 最重要的一笔——**把"没工作"的状态从惩罚变成了一种玩法**

> ⚠ **已知设计缺陷（玩家批评）**：任何武将都能自由切换威名，导致**不同武将只剩初始数值差异**；且部分终极威名达成条件过于简单（如关羽开局即"高手"）。教训：**威名/职业要有身份约束与有难度的达成条件，否则个性化会退化成通用化。**

### 5.3 成长轴的耦合关系（谁是谁的前置）

```
能力 ──┐
       ├──→ 任务效果好 ──→ 功绩 ──→ 品级 ──→ 身份权限 ──┐
绊 ────┘                                                  │
                                                          ↓
绊（数量 × 对方名声）× 身份 ──→ 名声 ──→ 威名 ──→ 专属指令 ─┐
                                                            │
                                                            ↓
                                          私兵 / 同道 / 举兵班底 ──→ 自立 → 统一
```

**读法**：
- **功绩线**是"体制内晋升"，出口是权力
- **名声线**是"江湖声望"，出口是能力与自由度
- 两条线在**举兵/自立**处合流——这就是终局玩法的入口
- 绊是同时喂养两条线的底层资源

**这是本次调研里最有价值的一张图**：它说明"多维成长"要成立，靠的不是维度多，而是**维度之间有明确的前置与合流关系**。单纯并列四个数字（声望/官职/人脉/宝物）是不够的。

## 六、验证机制（做了什么会被承认）

| 验证对象 | 判据 | 奖励 | 惩罚 |
|---|---|---|---|
| **任务** | 完成委托 | 功绩 + 资金 + 亲近感 | 无（可拒绝，失败惩罚弱） |
| **使命** | **360 天内**达成 | 武将忠诚上升 / 获得功绩 / 获得实绩（3 项） | 未达成则对应减少 |
| **品级** | 功绩达阈值 | 升品，解锁身份与权限 | — |
| **名声** | 绊武将数量与质量、身份高低 | 数值上涨 | — |
| **威名** | **条件 + 名声**双门槛，达成后**玩家自选** | 解锁专属指令与君令/战术 | — |
| **感情状态** | 送礼（对嗜好）/ 施恩 / 立伟业 | 感谢 / 好感 / 敬畏 / 迷恋，**均有有效期** | 到期消失，需重新经营 |
| **绊** | 亲近感满 + 感情状态达标 + **完成绊事件委托** | 成绊、习得传授特技、绊 LV 可继续提升 | — |
| **单挑** | 5 回合制，相克博弈 | 爱勇实绩 | 输 |
| **舌战** | 5 回合制，属性相克 | 爱才实绩；决定外交/评定/登用的结果 | 输 = 提案不被采用 |
| **战斗** | 兵力 + 战术 + 士气（PK 士气归零会溃散） | 以少胜多成为可能 | — |
| **终局** | 统一天下 / 主角死亡且未选继承 / 到 350 年 / 他势力统一 | 通关 | 失败 |

**观察**：
1. **验证是"宽进"的**——任务可拒绝、失败惩罚弱、绊事件可反复触发。这与它"角色扮演优先"的定位一致：**它不想用失败惩罚玩家，它用"机会成本"约束玩家**（时间流逝、感情状态过期）。
2. **唯一的硬期限是使命的 360 天**和**感情状态的时效**。时间本身就是主要约束。
3. **它没有像样的优势方抑制机制**——见 §7.4，这是被批评最狠的一点。

## 七、体验节奏

### 7.1 双时钟结构

| 时钟 | 周期 | 驱动什么 |
|---|---|---|
| **日** | 1 天 | 移动、任务执行、兵粮消耗 |
| **月** | 30 天 | 俸禄、感情状态（30 日/3 个月有效期） |
| **季** | — | 论功行赏（第 1 名是功绩大头） |
| **年 / 360 天** | 使命期限 | 评定、使命达成判定 |
| **世代** | 到 350 年 | 剧本结束；主角死亡可传继承武将 |

> 时间压力主要来自**感情状态时效**与**使命期限**，而不是资源枯竭。这是"人物驱动"型设计的一个特征：**稀缺的是时机，不是材料。**

### 7.2 五个阶段的内容变化（重点）

| 阶段 | 玩家身份 | 主要在做什么 | 主导动机 | 爽点 | 痛点 |
|---|---|---|---|---|---|
| **① 在野期** | 在野 / 游侠 | 跑城、接酒馆委托、讨贼、赚钱买名品、送礼结人 | 关系驱动 + 攒钱 | 白手起家的自由感；第一次结绊 | 没钱没人，必须"苟"；跑腿重复 |
| **② 一般武将期** | 九品～八品 | 接任务、提案争取高功绩活、师事涨能力、继续铺关系 | 任务驱动 + 成长驱动 | 第一次上战场、第一次升品 | 只能被动接活；被强制征召 |
| **③ 重臣 / 太守期** | 七品～五品 | 提案他人任务、开都市评定、管一城的内政与军备 | 任务驱动 + 自立驱动（开始布局） | 第一次"有下属"；能调动资源 | 内政任务重复度高；开始感到"刷" |
| **④ 都督 / 权力期** | 二品以上 | 管军团、任命太守、指挥大规模战役、笼络敌方 | 自立驱动 | 大规模会战；把嫡系安插进各城 | **身不由己**：AI 君主战狂，频繁被拉去出征；"忙里偷闲"做个人成长的时间被挤压 |
| **⑤ 君主 / 终局期** | 举兵或继位 | 统一战争 | 统一驱动 | 终局成就 | **滚雪球**：后期一战再战，缺乏挑战；重复作业感最强 |

**阶段轮替的核心规律**：
- ①→② 的变化是**获得"组织"**（从个体户到有编制）
- ②→③ 的变化是**获得"下属"**（从执行者到分配者）
- ③→④ 的变化是**获得"地盘"**（从一城到一片）
- ④→⑤ 的变化是**获得"目标"**（从做事到成事）

每一阶段玩家的**可操作集合都变大一圈**——这就是它维持新鲜感的方式。**不是换内容，是换权限。**

### 7.3 节奏曲线的三处塌陷（玩家批评归因）

| 塌陷 | 现象 | 设计层归因 |
|---|---|---|
| **后段滚雪球** | 大势力一战再战，连战不止 | **征兵全自动化**：不用人力不用财力、不减人口，战后还有大量伤兵回收 → 兵力只增不减，缺乏消耗侧约束。PK 加了行军士气递减也没能解决 |
| **中段"身不由己"** | 在大势力为官时，被评定强制拉去出征 | **自由度与角色扮演的冲突**：玩家没有主导评定的权力（哪怕身为军师/都督），AI 君主一律战狂 |
| **前段"等圆圈"** | 大量时间在看进度条圆圈 | **任务化的代价**：内政变成"接任务 → 等天数 → 报告"，中间没有可交互内容 |

> 这三条对我们是**预警而非参考**：我们做自动执行版本，前两条会被放大（自动化 = 更少的主导权；自动化 = 更容易滚雪球），第三条则正好是我们的机会（把等待时间填充成内容）。

### 7.4 抑制与平衡机制（附：这个角度原需求未列出，但对我们很关键）

**结论：三国志13 几乎没有像样的优势方抑制机制。**

| 潜在抑制点 | 实际效果 |
|---|---|
| 兵粮消耗 | 有，但 AI 不会用钱买粮，反而让 AI 后期"有兵不出" |
| 反包围网 | 有（小国抱团），但可用外交结盟完全规避，"结盟无上限" |
| 伤兵与征兵 | **反向作用**——征兵不减人口，伤兵大量回收 |
| 外交 | 电脑绝对诚信，不背叛；结盟可无限续 |

**归因**：它把设计预算全给了"人的体验"，平衡层基本没做。这在一个单机买断、以重复游玩为卖点的产品里可以接受；但**如果我们要做长线运营或多人，这层必须自己补**。

## 八、内容供给方式（原需求未列出，但对我们的风险 #1 直接相关）

| 供给源 | 规模 | 生产特性 |
|---|---|---|
| 剧本 | 本篇多个史实剧本；PK 追加 3 史实 + 1 假想 + 2 英杰传 | 一次性、高成本 |
| **英杰传** | 10+ 关卡，每关绑定一段史实节点 + 一组系统教学 | **教学与内容合一**，成本效率高 |
| 历史事件 / CG | 大量过场动画与配音 | 高成本高感知 |
| 武将 | 700→800 名，各自有列传、价值观、嗜好、语音 | 铺量为主，个体差异靠数值 + 嗜好 + 价值观 |
| 都市 / 集落 | 60 + 140 | 铺量 |
| **编辑系统** | 可编辑武将（上限 300）、名品（100）、战法（50）、事件，可网络共享 | **UGC 兜底长尾** |
| 名品 | 马 / 武器 / 书籍 / 酒 / 宝物，武将各有嗜好 | 关系系统的燃料 |

**两点值得抄**：
1. **英杰传 = 教学即内容**：每一关既推进历史叙事又教一个新系统，玩家在"想看下一关"的驱动下完成学习。这比单独的教程页有效得多。
2. **编辑系统 = 用 UGC 兜住内容长尾**：对内容量焦虑的产品，编辑器是成本最低的续航方式。

## 九、对「闲逛」V2 的映射与可迁移性

### 9.1 可直接迁移（结构层，改造成本低）

| San13 结构 | 迁移到挂机版的样子 | 与我们 V1 资产的对接 |
|---|---|---|
| **功绩 → 品级 → 权限** | 任务自动完成 → 功绩累积 → 官阶提升 → **解锁新的可去地点 / 可见人物 / 可做任务** | 直接替换 V2 原定的"技能等级解锁任务概率"，且叙事推力更强 |
| **亲近感 → 感情状态 → 绊事件 → 绊** | 四段漏斗**全部可离线推进**（亲近感随任务累积、感情状态自动进入、绊事件攒成待处理列表）；**在线只做最后一段** | 完美落在 V1 §4.6 红线上：离线给确定性部分，在线给结构差异 |
| **名声 = 人脉广度** | 名声 = Σ(已结交人物权重)，天然抗刷、天然需要广度 | 对应我们设想的"声望"维度，且给了它一个**可计算的公式** |
| **威名 = 自选职业 + 分支** | 可作为中长期目标：先声望达标，再**玩家自选路线**（文/武/商…），分支解锁不同任务池 | 对应"多维成长"，且自带重玩价值 |
| **师事 = 能力成长靠人** | "拜某某为师" → 离线自动累积经验，到期出师 | 把 V1 的"技能经验"重新包装成有对象的行为 |
| **名品 = 关系燃料** | 粮/矿 → **礼品/信物/宝物**，背包从"容量管理"变成"这次带什么去见谁" | 直接复用 V1 背包/仓库/回城循环，语义一转，价值翻倍 |
| **60 城 + 140 集落 + 人物分布** | 名臣分布在全国 → 天然形成跨州依赖 | 替换 V1 决策 #4 的"配方需要七八州材料"，理由更自然 |
| **阶段 = 权限扩张** | 每一阶解锁新一圈可操作集合，而不是换一批内容 | 直接作为我们的版本节奏规划模板 |

### 9.2 不可直接迁移 / 必须改造

| San13 元素 | 为什么不能直接要 | 改造方向 |
|---|---|---|
| **单挑 / 舌战**（实时小游戏） | 需要在线实时操作，无法挂机；且是纯技巧 | 降级为**离线可结算的对抗**（按属性算胜率，一次性 roll），或保留为**在线专属的一次性演出** |
| **战场即时指挥** | 整块时间、高操作量，与"5 分钟清完日常"冲突 | 完全剥离。战斗降级为**结算事件**（或干脆去掉，与 V1 决策 #8"任务必定成功"一致） |
| **内政任务化**（接任务→等天数→报告） | 中间段是空的，正是被批评的"等圆圈" | 我们反而要把**等待段填满**：路途上的事件、见闻、随机遭遇 |
| **被强制征召 / 评定裹挟** | 玩家厌恶"身不由己" | 挂机版天然没有强制，但也要注意：**自动化本身就会剥夺主体性**，必须靠"玩家设定倾向"补回 |
| **威名自由切换** | 导致角色个性化退化 | 我方可考虑：威名/路线一旦选定，切换有代价或冷却（但需与 V1 决策 #11"洗点免费"权衡） |
| **征兵/资源无消耗** | 后期滚雪球 | 我方必须有消耗侧（如出行消耗盘缠、送礼消耗宝物、时间上限） |

### 9.3 三个最该警惕的"照搬陷阱"

1. **把"任务"照搬成"跑腿"**：San13 内政任务化的失败在前。我们的任务必须有中间过程内容，不能只剩"出发 → 到达 → 结算"。
2. **把"关系"做成纯数值灌溉**：San13 的亲近感靠重复送礼，机械感强。要有**事件**才有记忆点（绊事件就是这个作用）。
3. **多维成长并列而无合流**：San13 的六轴之所以成立，是因为它们在"举兵/自立"处合流。我们若只做四个并列数字，很快会失去意义。

## 十、本次调研对 V2 方向评估的修正

对照上一轮我给出的评估，这份调研**强化**了两点、**新增**了两点：

| 项 | 变化 |
|---|---|
| 风险 #1 内容生产量 | **强化**：San13 用 800 武将 + 140 集落 + 大量事件才撑住规模；且它还有编辑器兜底。我们若要走这条路，内容策略必须先于系统设计定下来 |
| 优势"多维成长抗膨胀" | **强化**：得到实证——San13 的成长反馈全是离散、有名字、带叙事的里程碑，且轴之间有前置与合流 |
| — | **新增**：需要一个**消耗侧**。San13 因征兵无消耗导致后期崩溃，我们的自动产出必须有对应消耗（盘缠/礼品/时间），否则滚雪球比它更严重 |
| — | **新增**：**"英杰传 = 教学即内容"**的模式值得借鉴，可解决"新玩家看不懂多维成长"的引导问题 |
