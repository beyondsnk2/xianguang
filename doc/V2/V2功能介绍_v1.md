# V2 功能介绍文档

> **定位**：三国题材·地图挂机（idle）游戏。在线与离线共用同一套离散事件引擎（开发文档红线 3），玩家在 60×45 大地图上穿梭于 14 州 / 42 城 / 54 设施点位，接取任务、积累技能与品质、经营产出链。

## 〇、一句话游戏循环

```
出生州府 → 任务板接任务 → 自动走到设施 → 作业（needTime）→ 结算产出+属性经验
   ↑                                                            │
   └──────── 背包满→回州府存仓→空槽自动补位 ←──────────────────┘
离线：时间戳差分 → 同引擎离散推进 → 上线一次性补结算
```

核心体验：**技能只长等级不缩时长；品质决定做什么；评价（受属性调制）决定做得多好；三条线（A采/B造/C人）必须共升才做得出高阶货。**

## 二、玩法系统详解（核心 · 迭代定稿结论）

> 本节约等于 `设计_V2技能等级与任务品质_v1.md` 的结论版，去掉推导过程。开发任务见 `V2功能开发_v1.md` T2–T6。

### 2.1 技能：100 级 = 10 档
- 等级上限 **100**；**10 级一档，共 10 档**；经验**只由对应技能的任务**积累；**不动时长**（保住任务节奏基线）。
- 9 技能（A采3 / B造3 / C人3），档位**独立累积**（可专精偏科）。
- 每 10 级一次**里程碑节点**：节点1(Lv10)开2号品质、节点3(Lv30)材料阶位+1、节点7(Lv70)材料阶位再+1、节点8(Lv80)九品全开、节点9/10 纯提权重。节点3/7 是刻意的非线性获得感。
- 🔴 **同品咬合**（取代旧「档位差≤3软约束」，经济账非硬门槛）：**n 品 B 制造 = n 品 A 料（量）+ n 品 C 稀有料（质）** → A/B/C 三线必须共升到 n；不做任务即可（缺件自然停）。B 专精玩家后期产出垮已被驳回（B 是下游消耗核心+交易网络中心，缺口由跑商补）。

### 2.2 品质：九品 / 三段 / 滑动窗口
- 九品 1–9：**下品1-3 / 中品4-6 / 上品7-9**，玩家**只记三段**不记九个数。
- 🔴 **滑动窗口（核心机制）**：每技能档位只开放 **3 种品质**，窗口随档上移；下沿 `min(档位,7)` 只对下沿截断（截上沿会压扁窗口）。

| 技能档位 | 开放品质 | 说明 |
|---|---|---|
| 1档 Lv1-10 | 1,2,3 | 全下品 |
| 2档 | 2,3,4 | 窗口上移 |
| 3档 | 3,4,5 | |
| 4档 | 4,5,6 | 入中品 |
| 5档 | 5,6,7 | |
| 6档 | 6,7,8 | 入上品 |
| 7档 | 7,8,9 | |
| 8档 Lv71-80 | 7,8,9 | ✅ 触顶，九品全开 |
| 9–10档 | 7,8,9 | 🔴 封顶，只提权重 |

- 配置总基型 = **9技能×9品质=81 条**（每条绑定具体品质与专属 getItem）；玩家窗口内同时只碰 **9×3=27 种**可见任务。
- 窗口内**非等概率**：低档 50/35/15（低/中/高），高档 20/30/50 —— 档位越高越易刷到窗口内高品。
- ✅ **委活槽已取消**：低品断供是伪命题（A料三阶按当量1/3/9折算，精制料做下品绰绰有余）；真问题是「低端产物后期没用」（产物价值问题，非供给），留待跑商/后续补。

### 2.3 评价：四档 / 属性调制 / 临时桥
- **波动外置**：实际奖励 = 保底 1× + 增量 0~1×；四档 **拙0.0 / 平0.3 / 佳0.6 / 绝1.0**；**保底永1.0不倒扣**；技能经验不受评价影响。
- 🔴 **三类同品质收益必须不同**：**A 给量 / B 给效率（省料−25%+残料返还） / C 给关系（好感+稀有道具+图纸）**。A 类**永不给稀有材料**（红线①）。
- 🔴 **属性调制评价（Q19 已定）**：A←武力 / B←智力 / C←政治，统帅=全局节拍器（不进评价，缩单任务周期提吞吐）。设主力属性 `a`、任务属性基准 `base`，`r=a/base`：
  - `w0=clamp(1−r/3,0,1)`、`w2=w3=clamp((r−1)/2,0,1)`、`w1=1` → 归一化抽四档 → 乘率 `[1,1.3,1.6,2.0]`。
  - 硬规则：`r<1` 仅拙+平（佳/绝恒0）；`r≥3` 拙=0。属性只移概率，不动保底/封顶。
  - `attrBaseline = int(品质×4)` ∈ `{4,8,12,16,20,24,28,32,36}`（每层品质独立基准）。**该列已落 task/taskTpl 两表，目前为预留列，评价钩子（T4）接入前不生效。**
- 🔧 **V2 属性过渡供给（T7 已落地，接随机事件后删）**：V2 不实装随机事件，为跑通「属性→评价」机制，临时改为：A←武力 / B←智力 / C←政治 各 `+2`、30% 概率 `+1` 统帅。常量已由 `tick.ts` 顶部迁入 `constants.ts`（`ATTR_XP_PER_TASK / ATTR_LEAD_CHANCE / ATTR_LEAD_XP`），实现收敛在 `attrGain.ts::gainTaskAttrXp`，接入 F19b 时整段替换（`config.getAttrXp` 仍保持 null 的设计口径）。
  - **D4 验算（实测 167 任务/天、9技能均匀）**：主属性各 ≈111 XP/天 → **约0.6天lv5、~2天lv10、~7.6天lv20、~16天lv29-30、~30天lv40、~46天lv50**，硬上限 lv120（cum 29043）。统帅 ≈50 XP/天 → 约6天lv12-13、~17天lv20、~35天lv29-30，硬上限同 lv120。
  - 对照 `attrBaseline=4~36`（均值20）：主属性稳定 ~29-30 → 对品质2-8 `r≥1` 佳/绝可达，仅品质9(base36) `r≈0.8` 仍<1（顶层"够不着"可接受）。**评价钩子已被激活**（此前属性冻在2-5、r<1、卡死只出拙+平）。
  - ⚠ **重调提醒**：+2 按"genTask 等概率抽全81行、无技能/品质窗口"校；接 T2/T3（技能等级+品质窗口）后需下调或随技能缩放。

### 2.4 产出四层
- **材料层**：普通材料 **27 条**（3 A技能×9品质，轮转天然形成"同名三阶"对齐品质段：下品=普通/中品=上等/上品=精制）；稀有材料 **9 种 C类独占**（精铁/玄铁/雪莲/龙纹玉/犀角/朱砂/百年参/蚕丝/南药，按城独占）。
- **制成品层**：**35 制造族 × 9 品质 = 315 条**。投喂规则（红线④）：**n 品制造只吃 q≥n 的 A 料**（3品可用7品精制顶替，不准反向）；下品无图无稀 / 中品需稀无图 / 上品需图+稀。下品制造层保留（图纸门未开前制造线不空转）。
- **配方层（图纸）**：🔴 只由 C 类产（红线②）；人物好感≥阈值刷出；一次性解锁进配方册（非背包物）；永久有效。
- **其他**：好感(只C给) / 名品(上品C任务) / 跑商道具(机巧产出) / 势力好感(零和)。

### 2.5 三条红线 + 投喂铁律（须做成 parse 校验，见开发文档 T8）
| # | 红线/铁律 | 保证 |
|---|---|---|
| ① | 稀有材料只有 C 类能给 | A供量/C供质不被破，C不可被替代 |
| ② | 图纸只由 C 类给 | C 是 B 的前置，不可跳过 |
| ③ | 高阶配方=图纸城+材料A城+材料B城 三城互异 | 每件高阶货强制跨城 |
| ④ | 🔴 n 品制造只吃 q≥n 的材料；低品料永远喂不进高品制造 | 高品A料的档位投入不被低品按数量平替 |

①+②+③+④ 共同保证：三条线必须共升、每次做高级货都要跨城、高品料永远值钱。

### 2.6 同品咬合闭环
```
                （同品咬合：三条线都到 n 品）
A 采集 ── n 品材料（量）──┐
                         ├──→ n 品 B 制造 ──→ 兵器/消耗品/跑商道具
C 人物 ── n 品稀有 + 图纸（质）┘
```
A/B/C 都不能单独跑完全条链；玩家点开配方发现"缺6品玄铁"→回头刷6品C任务，体验上是自然长出而非被卡。
