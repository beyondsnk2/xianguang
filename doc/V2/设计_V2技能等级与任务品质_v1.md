## 一、技能 100 级 · 10 档（结论）
- 上限 **100 级**；**10 级一档，共 10 档**；经验**只由对应技能任务**积累；**不动时长**（保住任务节奏基线）。
- 9 技能（A采3/B造3/C人3），档位**独立累积**（可专精偏科）。
- 里程碑节点：Lv10 开2号品质 / Lv30 材料阶位+1 / Lv50 制成品+1配方 / Lv70 材料阶位再+1 / Lv80 九品全开 / Lv90 高品权重大提 / Lv100 满级精制品。节点3/7 为刻意非线性获得感。
- 🔴 **同品咬合**（取代旧「档位差≤3软约束」，经济账非硬门槛）：**n 品 B 制造 = n 品 A 料(量) + n 品 C 稀有料(质)** → A/B/C 三线必须共升到 n。

## 二、九品任务品质（结论）
- 九品 1–9 = **下品1-3 / 中品4-6 / 上品7-9**，玩家**只记三段**。
- 🔴 **滑动窗口**：每档只开放 **3 种品质**，下沿 `min(档位,7)`（只对下沿截断）；7档升满→8档触顶7-9。

| 技能档位 | 开放品质 | 技能档位 | 开放品质 |
|---|---|---|---|
| 1档 Lv1-10 | 1,2,3 | 6档 Lv51-60 | 6,7,8 |
| 2档 | 2,3,4 | 7档 Lv61-70 | 7,8,9 |
| 3档 | 3,4,5 | **8档 Lv71-80** | **7,8,9 触顶** |
| 4档 | 4,5,6 | 9–10档 | 7,8,9 封顶只提权重 |
| 5档 | 5,6,7 | | |

- 总基型 = **9技能×9品质=81 条**；窗口内同时只碰 **9×3=27 种**可见任务。
- 窗口内非等概率：低档 **50/35/15**、高档 **20/30/50**（档越高越易刷高品）。
- ✅ **委活槽已取消**：低品断供是伪命题（A料三阶按当量1/3/9折算）；真问题"低端产物后期没用"留待跑商/后续补（Q22 已定不做三阶）。

## 三、评价四档 / 属性调制 / 临时桥（结论）
- **波动外置**：保底1× + 增量0~1×；**拙0.0 / 平0.3 / 佳0.6 / 绝1.0**；保底永1.0不倒扣；技能经验不受评价影响。
- 🔴 **三类同品质收益必须不同**：**A 给量 / B 给效率(省料−25%+残料返还) / C 给关系(好感+稀有道具+图纸)**；**A 类永不给稀有材料**（红线①）。
- 🔴 **属性调制（Q19 已定）**：A←武力 / B←智力 / C←政治，统帅=节拍器(不进评价)。`r=a/base`：
  `w0=clamp(1−r/3,0,1)`、`w2=w3=clamp((r−1)/2,0,1)`、`w1=1` → 归一化抽四档 → 乘率 `[1,1.3,1.6,2.0]`。
  硬规则：`r<1` 仅拙+平；`r≥3` 拙=0。属性只移概率不动保底/封顶。
- `attrBaseline=int(品质×4)` ∈ `{4,8,12,16,20,24,28,32,36}`，已落 task/taskTpl 两表（**预留列，T4 接入前不生效**）。
- 🔧 **属性过渡供给（T7 已落地，接随机事件后删）**：`settleTask` 按 `attrGain.ts::gainTaskAttrXp` 给 A←武力/B←智力/C←政治 各+2、30%概率+1统帅（常量 `ATTR_*` 在 `constants.ts`，原 `tick.ts` 顶部的 `TEMP_*` 已删；`config.getAttrXp` 仍 null）。
  - 验算：主属性 ≈111 XP/天 → **~16天lv29-30、~30天lv40、~46天lv50，硬上限 lv120**（非 lv29-30 封顶，是持续缓增）；统帅 ≈50 XP/天 同步缓增。评价钩子已激活（此前冻在2-5、r<1、卡死只出拙+平）。
  - ⚠ **重调提醒**：+2 按"genTask 等概率抽全81行、无技能/品质窗口"校；接 T2/T3 后需下调或随技能缩放。

## 四、产出四层（结论）
- **材料**：普通 **27 条**（3A×9品质，轮转成同名三阶对齐品质段）；稀有 **9 种 C类独占**（精铁/玄铁/雪莲/龙纹玉/犀角/朱砂/百年参/蚕丝/南药，按城独占）。
- **制成品**：**35 制造族×9品质=315 条**；投喂铁律（红线④）：**n 品只吃 q≥n 的料**（3品可用7品精制顶替，不准反向）；下品无图无稀 / 中品需稀无图 / 上品需图+稀；下品制造层保留。
- **配方(图纸)**：🔴 只由 C 类产（红线②）；好感≥阈值刷出；一次性解锁进配方册；永久有效。
- **其他**：好感(只C) / 名品(上品C) / 跑商道具(机巧) / 势力好感(零和)。

## 五、三条红线 + 投喂铁律（须做 parse 校验，见开发文档 T8）
| # | 红线/铁律 | 保证 |
|---|---|---|
| ① | 稀有材料只有 C 类能给 | A供量/C供质不被破 |
| ② | 图纸只由 C 类给 | C 是 B 前置不可跳过 |
| ③ | 高阶配方=图纸城+材料A城+材料B城 三城互异 | 强制跨城 |
| ④ | 🔴 n 品制造只吃 q≥n 材料；低品料永远喂不进高品制造 | 高品A料档位投入不被平替 |

## 六、同品咬合闭环
```
A 采集 ── n 品材料(量)──┐
                      ├──→ n 品 B 制造 ──→ 兵器/消耗品/跑商道具
C 人物 ── n 品稀有+图纸(质)┘
```
A/B/C 都不能单独跑完全条链；玩家点开配方发现"缺6品玄铁"→回头刷6品C任务，体验自然长出而非被卡。
