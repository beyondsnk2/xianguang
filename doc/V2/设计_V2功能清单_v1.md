### 3.1 成长线

| # | 功能 | 定案要点 | 逻辑 | 配置 | 表现 |
|---|---|---|---|---|---|
| F19 | **主角技能系统** | ✅ **已定**：**只由挂机任务**积累（细密），**7–10 个**与任务类型一一对应；作用 = 产出倍率 + **解锁高品质任务/产物**；**不动时长** | ✅ | 🟡 | 🔴 | 见 `设计_主角成长_v2.md` |
| F19b | **属性来源改为随机事件** | ✅ **已定**：四维属性**只由随机事件**积累（细密），自由点做 **±10%** 修正 | ✅ | 🟡 | 🔴 | 取代 V1 的"任务发属性经验" |
| F19c | **弹性补偿机制** | ✅ **已定**：① 事件属性偏向受**称号/官职**影响；② **当前总属性 < f(个人等级) 的预期值**时**多刷属性事件**。算法：`gap=预期−当前` → 5 日追 90% → 换算每日事件条数 → 与**当日事件总数 ×10%** 取小；**不追平到 100%** | ✅ | 🟡 需 4 张配置项 | 🔴 | 三条约束：有上限 / 只给属性 / 斜率低于正常在线 |

| F21 | **职业称号** | **可随时切换的加成套装**，上位包含+新增（V2-19）；**并决定主角的作战方式**（V2-26） | ✅ | 🟡 | 🔴 |
| F22 | **势力归属（魏 / 蜀 / 吴）** | 必须先加入势力（V2-3）；为社交版预留 | ✅ | 🟡 | 🔴 |

| F24 | **功勋 → 品级 → 官职** | 品级**不带独立数值加成**、**上线后才提升**（V2-20）；官职给特定倍率与特殊结算项 | ✅ | 🟡 | 🔴 |
| F25 | **自选目标** | **常驻 + 定期更换 + 到期自动续期**（V2-6） | ✅ | 🟡 | 🔴 |
