# 交叉验证：《三国志13》 × 《太阁立志传5》

> 日期：2026-10-02
> 输入：`调研_san13.md`、`调研_太阁.md`
> 目的：**区分"这类题材的共有骨架"与"某一款的个人选择"**——前者是我们应当继承的，后者才是需要决策的
> 判据：只在**两款都出现、且形态可对应**时，才认定为共有骨架

---

## 一、为什么需要这一步

单看一款游戏，分不清哪些设计是**题材的必然**，哪些是**制作组的偶然**。两款都出现的东西，才更可能是"个人养成 + 大地图移动"这个品类的骨架，迁移风险低；只有一款有的，需要单独论证。

两款的可比性：
- 同为光荣、同为历史题材、同为"扮演一个人"
- 但视角不同（San13 偏"势力里的一个人"，太阁5 偏"彻底的个人人生"）、时代不同（2016 vs 2004）、内容组织方式不同
- **差异足够大，所以交叉验证有意义**

## 三、共有骨架：7 条（核心产出）

### 骨架 1｜双身份体系：职级轴 × 声望轴

两款都有**两条并行的成长轴**，且分工惊人一致：

| | 职级轴 | 声望/职业轴 |
|---|---|---|
| San13 | 品级（功勋驱动）→ **给权限**（重臣/太守/都督） | 威名（名声+条件驱动）→ **给能力与自由度**（专属指令） |
| 太阁5 | 武士阶级（功勋驱动）→ **给权限**（属下/带兵/城主） | 职业+称号（穷究驱动）→ **给能力与自由度**（开道场/创派/报上姓名） |

**为什么是两条而不是一条**：职级轴是"组织给你的"，受制于你在不在组织里；声望轴是"自己挣的"，在野也能涨。**两条轴的分离，是"在野也能玩"得以成立的结构前提。**

> 对我们的意义：**这一条可以直接定为 V2 的成长结构**。我们原设想的"官职 + 声望"恰好对应这两条轴，现在有了双样本验证。

### 骨架 2｜任务三层链：组织定方向 → 派活 → 玩家争取

```
上层：评定 / 使命（组织定方向，有硬期限）
中层：任务 / 主命（具体活儿，按身份分档）  ← 玩家可"提案"或"自选"
下层：执行 → 成果评价（分档，不是完成即满额）
```

**三处细节两边完全一致，值得单独记**：
1. **玩家有"争取活儿"的出口**（San13 提案 / 太阁5 自选主命）——纯被动接活会剥夺主体性
2. **有硬期限且逾期受罚**（San13 360 天 / 太阁5 到下次评定）
3. **成果分档**（完成度决定收益倍率，而非完成即满额）

### 骨架 3｜身份阶梯 = 权限阶梯，且"一城之主"是质变点

两款的阶梯都在**"拥有一座城"这一档发生质变**：

| | 质变前 | 质变后 |
|---|---|---|
| San13 | 一般武将：接活、执行 | 太守：开评定、任命重臣、分配任务 |
| 太阁5 | 家臣：接主命、执行 | 城主：开评定、给家臣下主命、管内政军备、筹措军资金 |

**质变的内容是同一个**：从**执行者**变成**分配者**。

再往上是"多城"（都督/国主），再往上是从体制内跳出（举兵/谋反）。

> **"每一档解锁的是新的可操作集合，不是新的数字"**——两款都用这个方式维持新鲜感，且都不需要额外内容成本。这是**省内容的成熟做法**，对我们的内容焦虑直接对症。

### 骨架 4｜关系是硬通货，是前置而非装饰

两款的关系系统都不是"好感度剧情"，而是**解锁资源的钥匙**：

| 关系能换到什么 | San13 | 太阁5 |
|---|---|---|
| 能力成长 | 师事习得特技/战法 | 拜师学技能 |
| 人才 | 登用、介绍 | 仕官、劝诱 |
| 战斗 | 同部队加成、战法强化 | — |
| 终局 | **举兵班底**（绊武将跟随） | — |
| 收集 | — | **人物卡**（下次可扮演） |
| 元系统 | 名声 = Σ 绊 | — |

**共同的多段漏斗结构**：
```
数值（亲近感/亲密度）
  → 状态或行动门槛（感情状态/每月一次上限）
    → 事件或条件（绊事件/亲密度满）
      → 结果（绊/人物卡）
```

**共同燃料**：礼物/名品，且**有针对性的正确选择**（San13 按嗜好送礼涨幅更高；太阁5 高价茶器效果好）。

### 骨架 5｜成长靠"向更强的人学习"，不是靠打怪

- San13：**师事**——能力差距越大，经验越多
- 太阁5：**修业/拜师/收徒/冥想**——向技能高于自己的人学，需好感度

共同点：**学习对象是具体的、有名的、需要你去找的**。成长不是抽象的"经验值增加"，而是"我拜访了某某某"。

### 骨架 6｜里程碑是"有名字的"，且同时具备多层价值

两款的顶级里程碑都不是数值，而是**称号/威名**，且都同时给三样东西：

| 价值层 | San13 威名 | 太阁5 称号 |
|---|---|---|
| ① 能力/指令 | 解锁专属指令与战术 | 加能力 +3~15 |
| ② **行为解锁** | 募兵、巡回、暗杀、仲裁 | 创立流派、开设道场、震慑山贼 |
| ③ **社会性** | 自报家门、影响他人感情状态 | **可"报上姓名"直接见大名** |

**第 ③ 层是最省成本的**：一个称号既能当数值又能当剧情钥匙，性价比极高。

### 骨架 7｜内容靠铺量 + 收集，且都有 UGC 兜底

- San13：800 武将 / 60 城 / 140 集落 + 编辑系统
- 太阁5：860 人 / 1080 卡 / 32 名胜 + 事件编辑器

**且两款都被批评了同一件事**：个体差异低（San13"不同武将只剩初始数值差异"；太阁5"大众脸复制粘贴，没收集欲望"）。

> **这是一个重要提醒**：铺量型收集有**边际效用递减**。我们如果要做人物收集，**数量必须克制，个体差异必须做实**——这恰好是小体量产品相对大厂的优势。

**补充观察（6.5 条，未达共有但两边都出现）**：多终局 / 正一位式的"非武力通关条件"——两款都提供了"不打仗也能算赢"的路径。对我们的"轻松"定位是正面信号。

## 四、差异对照：各自的独家解法

| 维度 | San13 的解法 | 太阁5 的解法 | 差异归因 |
|---|---|---|---|
| **在野怎么办** | PK 加威名六系统（侠客/商人），**补上去的** | 浪人是**原生状态**，且副职业可独立成线 | San13 母题仍是"势力里的人"，在野是补丁；太阁5 母题是人生模拟器，在野是一等公民 |
| **长线动力** | 换剧本/换人物重玩 | **跨存档卡片收集** → 解锁新主角/新剧本/新功能 | 太阁5 多一层元进度 |
| **重复动作怎么包装** | 基本没包装（等进度条） | **16 项技能各配一个小游戏** | 太阁5 把"表现形式"当设计预算花 |
| **个人经济** | 几乎无 | 跑商/米相场/副职业生产/投资 | 太阁5 有商人职业，必须配经济系统 |
| **战斗** | 三层（战略+战术战场+单挑舌战），PK 还加了军议 | 两层（个人战+战棋合战），且被批评弱化 | San13 吃到了更多战斗预算 |
| **学习是否可逆** | 威名可自由切换（被批评导致同质化） | 职业转换有代价（辞官、学不到其他职业卡） | **太阁5 的选择更重，因此更有分量** |

**两条值得单独说的差异**：

1. **太阁5 的"职业转换有代价"优于 San13 的"威名可自由切换"**。后者被明确批评"导致不同武将只剩初始数值差异"。→ **推论：身份/路线选择要给一点不可逆性，否则个性化退化成通用化。**（注意：这与我们 V1 决策 #11"洗点免费"存在张力，需要单独权衡。）

2. **太阁5 的卡片收集是这套题材里最长的长线解法**。San13 没有这一层，所以它的重复游玩完全依赖"换个人重开"，而每次重开都从零开始。→ **若我们要做长线，这一层值得抄形式。**

## 五、共同缺陷：5 条（说明是题材的固有难题，不是个案）

| # | 缺陷 | San13 表现 | 太阁5 表现 | 归因 |
|---|---|---|---|---|
| 1 | **后期重复 + 无优势方抑制** | 征兵全自动 → 后期一战再战、连战滚雪球 | 天下大势已定后几十座城变体力活 | 两款都把设计预算给了"人的体验"，平衡层没做 |
| 2 | **自由时间与刚性周期不匹配** | "大部分时间在看一个圆圈进度条" | "38 天空档，修业要 20 天，恰好不够两次，只能睡觉" | **行动颗粒度 vs 周期长度**没对齐 |
| 3 | **铺量内容的个体差异低** | "不同武将只剩初始数值差异" | "大众脸复制粘贴，没什么收集欲望" | 铺量必然稀释个体 |
| 4 | **战斗层都没吃到足够预算** | 内政任务化后深度下降；PK 才补军议/战术 | "攻城=撞城门，野战靠几个技能吃遍天"，被评弱化 | 两款的重心都在"人"不在"打" |
| 5 | **强制性与身不由己** | 大势力为官时被评定强制拉去出征；不能主导评定 | 忍者不能自选主命；评定强制到场、迟到扣功勋 | 组织归属感与自由度冲突 |

> **这五条里，#1 和 #2 对我们最关键**：#1 我们会放大（自动化 = 更容易滚雪球），#2 是我们的机会（见 §7）。

## 六、交叉验证出的因果关系（本次调研最有价值的部分）

> 方法：**找两款做了不同选择、得到不同评价的同一件事** → 差异即因果。

### 因果 A｜重复动作必须换皮，否则体感崩塌

| | 做法 | 评价 |
|---|---|---|
| 太阁5 | 技能成长 = 16 个不同小游戏 | 正面："避免枯燥刷级" |
| San13 | 内政 = 接任务 → 等天数 → 报告 | 负面："大部分时间在看一个圆圈进度条" |

**同一件事**（反复执行同类动作），**表现形式不同，评价两极**。
→ **对我们的直接推论**：我们的任务是完全自动的，玩家连"点"都没有。**如果不给过程内容，我们的体验会比 San13 的"等圆圈"更空。**

### 因果 B｜成长不依赖操作精度 → 自动化可行

- 太阁5 修业是**经验累积制**："即使一次都没成功，只要次数多了，技能一样可以升到 4 级"
- San13 师事只需满足条件即执行，成果靠数值差

→ **两款的成长都不靠操作精度，靠"次数 + 条件"。** 这是对我们自动化方向最有力的正面证据：**这类题材的成长本来就是可离线结算的。**

（例外：太阁5 的"星级"只能靠实战使用提升、San13 的单挑/舌战需要实时操作——这两处恰是**不适合自动化**的部分，需要单独改造。）

### 因果 C｜成果差异的来源，决定了玩家的技巧点在哪

- 两款的成果差异都来自**执行过程的投入**（小游戏打得好、跑得多、成果超标）
- **但我们的版本里，执行过程是自动的**——玩家没有过程可投入

→ **关键推论：我们的"技巧点"必须前置到"出发前的决策"上。**

| 游戏 | 技巧点位置 | 我们的版本 |
|---|---|---|
| San13 / 太阁5 | 执行过程中（怎么跑、做多好） | ❌ 不可用（自动执行） |
| **我们必须做的** | — | ✅ **出发前：带什么、什么时候去、路线怎么排、先见谁** |

**这与 V1 已定的三项玩家操作（拖动排序 / 调整装备专精 / 处理事件）正好吻合**——现在有了来自双样本的理论依据：**在一个自动执行的游戏里，技巧点只能存在于"配置"环节。**

### 因果 D｜跨存档元进度是长线动力的关键变量

- 太阁5 有 → 长线动力极强，"至今仍充满活力"
- San13 无 → 长线靠重开，且每次从零

→ 若我们要做长线（而不是一局就结束），**必须有跨存档的元进度**。形式可以不是卡片，但功能要对等：**解锁新的可玩内容**。

### 因果 E｜权限扩张比内容扩张更省成本

两款都靠"可操作集合变大"维持新鲜感，而不是靠"换一批内容"。
→ 在我们的内容焦虑下，**优先设计"解锁什么"，而不是"新增什么"。**

### 因果 F｜个人经济线是"不打仗也能玩"的基础设施

- 太阁5 有完整经济线 → 商人/茶人/铁匠路线成立，副职业是主职业的财源与社交工具
- San13 无个人经济 → 在野只能靠 PK 威名补，且"赚钱"这件事缺乏玩法

→ 我们要做"轻松"、要弱化战斗，**经济/社交线必须有实质内容，不能只是数字**。

## 七、对「闲逛」V2 的交叉结论

### 7.1 经双样本验证、可直接迁移（高置信）

| # | 结构 | 置信度 | 备注 |
|---|---|---|---|
| 1 | **双身份体系**：职级轴（给权限）× 声望轴（给能力/自由度） | 高 | 直接对应我们的"官职 + 声望" |
| 2 | **身份阶梯 = 权限阶梯**，质变点在"一城之主" | 高 | 省内容成本的成熟解法 |
| 3 | **关系四段漏斗** + 礼物作为燃料 | 高 | 可直接映射离线/在线切分 |
| 4 | **"向更强的人学习"作为成长动作** | 高 | 对应我们的"拜会/师事" |
| 5 | **有名字的里程碑，且三层价值**（能力+行为+社会性） | 高 | 性价比最高的里程碑设计 |
| 6 | **任务链：上层定方向 + 玩家可争取 + 硬期限 + 成果分档** | 高 | 成果分档可保留（从前置决策产生） |
| 7 | **多终局 / 非武力通关条件** | 高 | 支撑"轻松"定位 |
| 8 | **多职业/多路线**（转换有代价） | 中高 | 需与 V1 #11 权衡 |
| 9 | **UGC / 编辑器兜底内容长尾** | 中 | 两边都有，但我们是网页端，形式待定 |

### 7.2 必须新建（两款都没有，但我们必须要）

| # | 为什么必须新建 | 说明 |
|---|---|---|
| 1 | **消耗侧** | **两款都因缺少消耗侧而后期崩溃**（共同缺陷 #1）。我们的产出是全自动的，崩溃会更快。必须有：盘缠、礼品消耗、时间上限、容量约束中的至少两种 |
| 2 | **过程内容** | 因果 A 的直接结论：自动执行 = 没有过程 = 比"等圆圈"更空。**路途事件是必需品，不是装饰品** |
| 3 | **前置化的技巧点** | 因果 C：技巧点只能放在"出发前的配置"上（带什么、先见谁、路线排序） |
| 4 | **跨存档元进度** | 因果 D：学太阁，形式可改为人物图鉴 / 见闻录 / 名所收集 |

### 7.3 我们的机会窗口（两款的共同缺陷，恰是自动化的强项）

| 共同缺陷 | 它们的表现 | 我们的位置 |
|---|---|---|
| **#2 自由时间无处安放** | San13"等圆圈"；太阁5"38 天空档只能睡觉" | **我们 91% 的时长就在路上**——在它们那里是要跳过的空隙，在我们这里是主舞台。**这是本项目最确定的机会** |
| **#1 无优势方抑制** | 两边后期都崩 | 我们纯前端、数值完全可控，可以随时加消耗侧与上限 |
| **#3 个体差异低** | 铺量导致复制粘贴 | 我们量级小（几十个人物），可以做实每个人的专属内容——**这是大厂做不到的** |
| **#5 身不由己** | 强制征召、不能自选 | 我们没有组织强制，天然规避；但要防"自动化剥夺主体性"，靠"玩家设定倾向"补回 |

### 7.4 三条红线（从共同缺陷反推）

1. **自动任务不能是纯进度条** —— 过程必须有内容（路途事件、见闻、遭遇）
2. **必须有消耗侧** —— 否则比 San13 的滚雪球来得更快更猛
3. **人物数量克制、个体差异做实** —— 吸取两款"铺量稀释个体"的教训
