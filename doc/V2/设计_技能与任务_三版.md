# 技能与任务类型：三版设计（2026-10-03）

> ✅ **已定案：采用「版本二 · 演义奇工」。** 版本一、版本三**落选**，保留为决策记录。
>
> **定案同时确认的三项**：① B 类保留「基础制造」层 ② 「出使」给的是**对人**的好感 ③ C 类给好感**不与 V2-10 冲突**。

## 🔑 定案时新增的设计原则：任务刷出 = 表现随机 + 后台伪随机控制

> **用户原话**："玩家看到任务都是随机刷出的（实际上肯定有伪随机控制）"
>
> | 层 | 内容 |
> |---|---|
> | **表现层** | 玩家感知为**纯随机** → 不产生"刷不出是因为系统针对我"的挫败 |
> | **逻辑层** | 后台用**权重调控**，保证：① 前置达标后能刷出（如「图纸门」）② A/B/C 三类占比稳定 ③ 高品质任务按称号概率出 |
>
> ✅ 这条原则**正当化了**此前提的所有"柔性引导"（图纸达标即刷、技能影响事件偏向），
> 把它们统一成同一个机制，而不是各开一套特例。
> → 也因此**不需要给玩家任何"保底进度条"**——随机感本身就是体验的一部分。

## 〇、共同前提

| # | 前提 |
|---|---|
| P1 | 任务 = **挂机线**，全自动执行，**玩家只拖顺序（少跑路）** |
| P2 | 挂机层已承载 **2 个维度信息**（拖顺序 + 高品质任务惊喜）→ **任务种类必须收敛**（目标 9 个） |
| P3 | 技能 **细密**（连续经验条），**只由对应任务积累**；**不动时长**，只影响产出量与高品质解锁 |
| P4 | 任务**无 TTL**；任务**不发属性经验**（属性改由随机事件给） |
| P5 | 产出走 **「波动外置」**：保底 1× + 增量 0~1×；高品质物品是顶层惊喜 |
| P6 | **强制跨州依赖**（V1 决策 #4）必须由任务链承载 |
| P7 | 装备系统在战斗之后（第一版内）；跑商需要**货品（按趟消耗）** |
| P8 | 时限外置：越偏收集越短，越偏数值越长（作用于**随机事件**，不作用于任务） |

**三类的分工定位**（三版通用）

| 类 | 定位 | 提供什么 | 类比 |
|---|---|---|---|
| **A 采集** | **广度** | 基础材料，**分布在地图各处** → 承载跨州依赖 | 供应链上游 |
| **B 制造** | **深度** | 消耗材料 → 兵器/消耗品/跑商道具 → **配方树** | 供应链下游 |
| **C 人物** | **机会** | 与三国人物互动 → 关系/情报/图纸/名品线索 | 非物资线 |

> 技能总数：**9 个（A3 + B3 + C3）**，落在此前商量的 7–10 区间内。

> 一句话：**幻想材料进入常规生产链，世界仍是历史世界。** 最贴《三国演义》。

**A 采集**

|---|---|---|---|

| **猎奇** | 涉险 | 山林 / 南中 | 皮角、**藤甲料、犀革** |

**B 制造**

| 技能 | 任务 | 设施 | 产物 |
|---|---|---|---|
| **锻造** | 铸兵 | 铁匠铺 | 兵器、**玄铁兵（名品）** |

| **机巧** | 制器 | 机巧坊 | 连弩、**木牛流马（跑商道具）** |

**C 交接**

| 技能 | 任务 | 设施 | 产物 |
|---|---|---|---|
| **访道** | 访异人 | 道观 / 隐庐 | **稀有材料**（朱砂·丹砂·灵芝）+ **人物好感** + 〔条件触发的**符箓图纸**〕 |
| **结义** | 结交 | 校场 / 酒肆 | **稀有材料**（良马筋·异铁）+ **人物好感** + 〔条件触发的**名器图样**〕 |
| **出使** | 使节 | 使馆 | **稀有材料**（藤甲料·犀革）+ **人物好感** + 〔条件触发的**异邦图纸**〕 |

> 三类 C 技能**结构完全一致**（稀有材料 + 好感 + 条件图纸），只有内容不同 → 玩家只需理解一遍。
> 详见下文「C 类的产出与「图纸门」」。

> 🔑 **本版独有的闭环**：**A 供料 + C 供图 + B 制造**
>
> ```
> A 采集 ──材料──┐
>                 ├──→ B 制造 ──→ 兵器 / 消耗品 / 跑商道具
> C 人物 ──图纸──┘
> ```
>
> **C 类不是平行线，而是 B 类的前置。** 三类真正咬合成一条链，
> 而且 C 类仍然是"和三国人物互动"的内容，符合你的定性。

| 优点 | 风险 |
|---|---|
| 三类互相咬合，不是三条平行线 | 需要引入"**图纸**"这一新物品概念 |
| **幻想材料正好是"高品质产物"的天然载体**（朱砂/丹砂/玄铁/藤甲）→ 完美接「波动外置」 | 内容量比版本一高 |
| **木牛流马等直接接跑商线**（提升商队），B 类与 F 经济线打通 | — |
| 跨州依赖由"材料分布 + 图纸产地"双重承载 | — |

### 🔑 C 类与 B 类的关联机制（版本二核心，2026-10-03 补充）

**总原则：A 提供「量」，C 提供「解锁」与「稀有辅料」，B 是产出端。**

```
A 采集（3 技能）──基础材料────┐（决定"够不够"）
                               ├──→ B 制造（3 技能）──→ 兵器/消耗品/跑商道具
C 人物（3 技能）──图纸 + 稀有辅料┘（决定"能不能造 / 造得好不好"）
```

**一对一映射（这是本机制的关键，好记且不重叠）**

| C 技能 | 产出 | 主要喂给 | 为什么是它 | 具体例子 |
|---|---|---|---|---|
| **访道** | **稀有材料**（朱砂/丹砂/灵芝）+ **人物好感** | **丹鼎** | 方士本身就是丹药与符水的来源 | 于吉→符水；左慈→九转丹（图纸由好感触发） |
| **结义** | **稀有材料**（良马筋/异铁）+ **人物好感** | **锻造** | 名器是武将的私人物，只能从本人处得来 | 关羽→青龙偃月刀；张飞→丈八蛇矛；赵云→亮银枪 |
| **出使** | **稀有材料**（藤甲料/犀革）+ **人物好感** | **机巧** | 技法在外邦，需外交才能引入 | 南中→藤甲；西域→连弩改良；吴地→楼船 |

> **为什么图纸必须由 C 类独占**：如果 B 类能自己研究出图纸，C 类就可以被跳过，
> 玩家的最优解会退化回"只做 A + B"。**独占是 C 类存在意义的唯一保障。**

**稀有辅料（"量"之外的"质"）**

| C 技能 | 稀有辅料 | 作用 |
|---|---|---|
| 访道 | 朱砂、丹砂、灵芝 | 高阶丹药 / 符水的必需料 |
| 结义 | 良马筋、异铁 | 名器的必需料 |
| 出使 | 藤甲料、犀革、海外异材 | 藤甲 / 船上用料的必需料 |

> 用户对 B 类的原始描述就是"**以 A 类材料为主，配合少量其他任务获得的材料**"——
> 这个"少量其他材料"正好落在 C 类身上：**A 供量、C 供质。**

**三条配套约束（防止机制跑偏）**

| # | 约束 | 理由 |
|---|---|---|
| ① | **图纸 = 一次性解锁的配方条目**，进"配方册"，**不是背包物品** | 不占背包、不怕爆仓、不需要反复刷——比"持有图纸道具"更挂机友好 |
| ② | **图纸获取后永久有效** | 与"任务无 TTL""不惩罚"一脉相承，杜绝"图纸过期"类设计 |
| ③ | **C 类任务也上同一块任务板**（可拖顺序），但**占比低** | 让"先去访道还是先采药"成为**拖顺序时的真实权衡**；同时占比低，不撑爆挂机层的 2 维信息量 |

**⚠ 需要盯住的风险**

> C 类成为 B 类的前置后，**C 类的刷出频率就成了 B 类进度的闸门**。
> 若 C 类任务刷得太少 → 玩家会发现"矿堆成山但造不出东西"，体验断崖。
> → 建议：**图纸类任务是"达标即刷"**（满足条件后提高刷出权重），而不是纯随机。
> → 这条与 `设计_主角成长_v2.md` §7.3「技能影响事件偏向」同属"柔性引导"，规则可统一。

### C 类的产出与「图纸门」（2026-10-03 简化定案）

> ❌ **「术法」「同盟契」已废弃**——过于复杂，砍掉。
> ✅ **C 类的产出收敛为三种**，且**三类 C 技能结构完全一致**（只有内容不同）。

#### 1. C 类产出（统一三种）

| 产出 | 说明 |
|---|---|
| **① 稀有材料** | C 类专属，A 类拿不到 → **A 供量、C 供质** |
| **② 人物好感度** | 与三国人物的关系进度 |
| **③ 图纸** | ⚠ **不是常态产出**：**满足前置条件时，高概率触发一个"额外给图纸"的 C 类任务** |

#### 2. 图纸的触发条件

```
人物好感度 ≥ 阈值（读配置）
      ↓ 高概率
刷出一个「额外给图纸」的 C 类任务
      ↓ 完成
获得 1 张图纸（永久有效，写入配方册）
```

> 🔑 **这个顺序很三国**：先和关羽混熟（好感），熟了才可能把**青龙偃月刀图样**交给你。
> **图纸不是打怪掉落，是"关系到位"的结果。**

#### 3. B 类的两级门（关键补充）

> 🔴 **必须分两层，否则前期一个 B 类任务都不会刷出。**

| 层 | 前置 | 是否常态可刷 | 内容 |
|---|---|---|---|
| **基础制造** | 只需 **A 类普通材料** | ✅ **常态刷出** | 日常生产品（普通兵器、常用药、车具） |
| **高阶制造** | **图纸 + 稀有材料**（两者**同时满足**） | ❌ **满足后才进任务池** | 名器、符水、藤甲、木牛流马等 |

> ✅ 效果：**图纸 + 稀有材料 = 打开高阶制造的钥匙。**
> 玩家会自然形成循环：**嫌 B 高阶刷不出来 → 去多刷 C 类 → 拿稀有材料与好感 → 好感到阈值 → 拿到图纸 → B 高阶解锁。**

#### 4. 版本二 C 类内容（按新结构统一）

| C 技能 | 稀有材料 | 可触发的图纸 | 交互对象（好感） |
|---|---|---|---|
| **访道** | 朱砂、丹砂、灵芝 | 符箓图纸 → 符水 | 于吉 · 左慈 · 管辂 |
| **结义** | 良马筋、异铁 | 名器图样 → 青龙偃月刀 / 丈八蛇矛 | 关羽 · 张飞 · 典韦 |
| **出使** | 藤甲料、犀革、海外异材 | 异邦图纸 → 藤甲 / 连弩改良 / 楼船 | 使者 · 异邦人物 |

> 结构统一后，**三类 C 技能玩家只需理解一遍**，认知负担大幅下降（符合 P2：挂机层信息必须收敛）。

#### 5. 🔴 三个必须一起确认的点

| # | 问题 | 我的建议 |
|---|---|---|
| 1 | **B 类基础层是否保留？** | ✅ **必须保留**。否则「图纸门」未打开前，任务池里只有 A + C，制造线长期空转 |
| 2 | **「出使」给的好感是对人还是对势力？** | 建议**对人的好感**（使者 / 异邦人物），保持三类 C 结构一致；若要给势力好感，需另开一条产出（会打破"三种产出"的简洁） |
| 3 | **人物好感 vs V2-10「关系靠事迹传播」的张力** | ⚠ 见下方风险说明 |

> ⚠ **风险说明：C 类给好感，是不是回到了"主动灌溉"？**
> V2-10 明确否定了"主动灌溉"，理由是要规避两款原作"刷关系机械"的批评。
>
> ✅ **但这里不构成冲突，原因有两条**：
> 1. **任务是自动执行 + 随机刷出的**——玩家**不能指定"我要反复刷关羽"**，他只能拖顺序。
>    所以不存在"机械重复刷同一个人"的操作。
> 2. **C 类的好感只是"渠道之一"**，与事迹传播**并行**：事迹传播仍负责一对多的被动扩散，
>    C 类负责"深度交往"这一小部分人。
>
> → 结论：**C 类给好感是可接受的，但它是"深交渠道"，不是"刷关系入口"。**
> 前提是**任务目标不可由玩家指定**——这条要作为红线守住。

## 版本三：三方异术（魏蜀吴分化）❌ 落选（留待社交版）

> 一句话：**A/B/C 三个技能不变，但每类的具体内容按势力分化**，
> 魏重工造、蜀重机巧与南中物产、吴重舟船与海外。**跨州依赖最强。**

| 势力 | A 采集 | B 制造 | C 交接 |
|---|---|---|---|
| **魏**（工造） | 冶铁（铁石、石炭）、屯田（粮） | 军器监（兵器、**攻城器**） | 召贤（荀彧·郭嘉 → 内政与谋略加成） |
| **蜀**（机巧 + 南中） | 采药（蜀中草药）、南征（**藤甲、犀革、丹砂**） | 机巧（**连弩、木牛流马、八阵图**） | 结交关羽·张飞（**人物好感**） |
| **吴**（舟船 + 海外） | 渔盐（海盐）、采珠（**珍珠、玳瑁**） | 船坞（**楼船、舟楫**）、织造（越布） | 会盟（周瑜·鲁肃 → **水战加成**）、使海（**海外异货**） |

> 🔑 技能仍是 **9 个**（A3/B3/C3），但**技能内容随势力/州郡分化** →
> 玩家想拿到"楼船图纸"就必须去吴地 → **跨势力取料 = 最强的跨州依赖**。

| 优点 | 风险 |
|---|---|
| 势力差异最鲜明，为**社交版势力战**预埋了天然动机 | **内容量 ×3**（三个势力各一套），成本最高 |
| 跨州依赖最硬（势力封锁，不只是距离） | 与"必须先加入势力"（V2-3）耦合：加了魏就难拿吴地物产 → 需确认不会变成**死锁** |
| 势力特产的**跑商价差最大**，经济线最厚 | 教学成本最高 |
