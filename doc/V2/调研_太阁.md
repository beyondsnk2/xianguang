# 调研：《太阁立志传5》功能结构拆解（策划视角）

> 版本基准：**《太阁立志传5》(2004) +《太阁立志传5 DX》(2022 高清重制)**
> 调研日期：2026-10-02
> 用途：与《三国志13》做**交叉验证**，提炼"个人养成 + 大地图移动"这类题材的共有骨架
> 范围约定：**本轮只拆功能框架，不做数值反推**（出现的少量数值仅为说明结构形状）
> 资料来源：百度百科、Gamersky 上手指南、游侠网完全攻略手册、新浪游戏技能修炼篇、游研社/Bangumi/Steam 评价

---

## 〇、一句话结论

**太阁5 的设计母题是"人生模拟器"——它把"出人头地"这件事拆成了四条可独立完成、互相不通用的赛道（武士/忍者/海贼/商人），并用一套跨周目的「卡片收集」把"重玩"本身变成了进度。**

如果说三国志13 是**"在势力里往上爬"**，太阁5 就是**"先选一种活法，再把它做到天下第一"**。二者的差别不在系统复杂度，而在**玩家主体性的落点**：San13 你始终是某个组织的一员，太阁5 你可以彻底不属于任何组织（浪人），甚至一辈子不碰战争。

对本项目而言，太阁5 贡献了三件 San13 没有的东西：
1. **跨周目元进度**（卡片收集 → 解锁可扮演人物 / 剧本 / 功能）
2. **把重复动作包装成小游戏**（修业 = 小游戏，而不是进度条）
3. **完整的个人经济线**（跑商、米相场、副职业生产）

| 项 | 值 |
|---|---|
| 发售 | 2004-03-12（PC / PS2 / PSP）；DX 高清重制 2022-05-19（PC / Switch / PS4） |

| 系列坐标 | 《太阁立志传》系列**最后一作**；与《三国志7/8/10》《大航海时代4》同属光荣"个人扮演"黄金期 |

## 二、设计母题推导出的取舍

| 母题推论 | 具体取舍 | 副作用 |
|---|---|---|
| 人生有多种活法 | **4 条主职业赛道**，各自有独立的"统一"目标 | 各职业完成度不均，剑豪/茶人/铁匠/医师后期靠重复操作刷"天下第一" |
| 成长要看得见、玩得到 | 技能成长全部通过**小游戏**（修业）而非数值累积 | 小游戏数量过多，"来回点点点让体验割裂" |
| 出人头地要有台阶 | 武士阶级 ladder + 城主/国主/大名 | 后期扩张拖沓，几十座城变体力活 |
| 人脉即资源 | 亲密度 → 学技能 / 仕官 / 劝诱 / 得人物卡 | 每月对同一人只能"送礼"或"茶席"二选一，刷关系机械 |
| 收藏欲能撑住重玩 | **跨存档的卡片收集元系统** | 不查攻略几乎无法触发部分事件 |
| 自由要有代价 | 体力 / 疾病 / 评定期限 | 评定强制到场，"空档时间"难打发（详见 §7.3） |

## 三、功能结构总图

### 3.1 职业层（选活法）

| 类型 | 职业 | 统一目标（"天下第一"条件） | 特性 |
|---|---|---|---|
| 主职业 | **武士** | 所属大名家支配全国 180 城 / 同盟合计支配 / 获任"正一位" | 最主流，可收最多人物卡；沿史实走 |
| 主职业 | **忍者** | 支配全国 12 个忍者之里 / 支持的大名家统一 / 学会全部忍术 | **不能自选主命**（被指派），个人战多，武力优先 |
| 主职业 | **海贼（水军）** | 支配全国 16 个海域 / 支持的大名家统一 | 与伙伴徒党一同执行主命；依赖"城门爆破"；入门最轻松 |
| 主职业 | **商人** | 所属商家成为全国 15 个商业圈的商人司 | **完全没有军队**；靠奉纳金与铁炮支援大名；系统最特殊 |
| 终局方向 | **剑豪** | 京之御所"天览试合"优胜 / 开道场收门徒 | 需武艺修炼 + 流派秘技；可最快通关 |
| 副职业 | **冶炼匠 / 茶人 / 药师 / 师范** | 各自有结局（献刀 / 茶室外交 / 名医 / 道场） | 在主职业之外并行，是主要**财源**与**社交工具** |
| 无所属 | **浪人** | 想干什么干什么 | 无俸禄但完全自由；很多玩家刻意先当浪人练满技能再出仕 |

> ⚠ 各资料对"主职业数量"口径不一（4 或 5，剑豪是否单列）。此处按**"4 主职业 + 剑豪为终局方向 + 4 副职业 + 浪人状态"**理解。

**职业转换规则**：忍者/海贼/商人之间可互转，但**转武士需先辞去原势力职务**；且成为武士后就学不到忍者/海贼的技能卡——**"什么时候转职"本身成为策略**。这是一个很妙的设计：**职业选择是一次性的路径分岔，不是随时可洗的点**。

### 3.2 人物层（我是谁）

| 子系统 | 内容 |
|---|---|
| **5 能力** | 统率 / 武力 / 智谋 / 政务 / 魅力 |
| **16 技能** | 统率系：足轻、骑马、铁炮、水军<br>武力系：弓术、武艺、忍术<br>政务系：建筑、开垦、矿山、算术<br>智谋系：军学、辩才<br>魅力系：礼法、茶道、医术 |
| **技能等级** | **4 级**（可修业达成）→ **星级★★★★**（只能靠实战/反复使用升上去，修业无法达到） |
| **学习门槛** | 能力值决定上限：40 可修到 1 级、50→2 级、60→3 级、70+→满级（此限制主要针对 NPC；玩家自己可修满 4 级） |
| **贵重品** | 0–7 级，**5 级以上带属性加成**；可购买/行商推荐/委托盗取/**自己制造** |

> **"4 级靠修业、星级靠使用"**这条很关键：它把"学"和"用"分成两段，**用是学不出来的**。这与我们 V1 里"技能等级管多强、装备管刷什么"的职责解耦思路是同一类设计哲学。

### 3.3 成长层（怎么变强）—— 本作最有辨识度的一层

**技能成长 = 玩小游戏（修业）**。每一项技能对应一个不同的小游戏：

| 技能 | 修业场所 | 小游戏形态 |
|---|---|---|
| 足轻 | 武将家 | 模拟野战 |
| 骑马 | 马屋 | 赛车式躲箭（有惯性，鼠标控制左右） |
| 铁炮 | 锻冶屋 | 移动靶射击 |
| 水军 | 水军砦修业场 | 模拟水战 |
| 弓术 | 武将家 | 固定靶射击（需调整角度与力度） |
| 武艺 | 道场 | 个人战，一对多 |
| 军学 | 武将家 | "四角阵崩"，类似连连看 |
| 忍术 | 忍者之里修业场 | 限时从候补头像中找出画轴里的头像 |
| 算术 | 商家 | 四则运算填空（允许分数与负数） |
| 医术 | 医师宅 | 分药 / 调药 |
| 建筑 / 开垦 / 矿山 | 各处 | 各自的小游戏 |
| 茶道 / 礼法 | 茶人宅 / 寺 | 排列茶器等 |
| 辩才 | 武将家 | — |

**三条并行的技能习得路径**：
1. **修业**（小游戏，经验累积制——即使一次都没成功，攒够经验也能升到 4 级）
2. **拜师 / 收徒**（传授；对方技能等级不能低于自己；需好感度；学全师父秘技 → 得**流派印**）
3. **冥想**（在名胜 / 山 / 瀑布 / 寺社进行，**可悟出师父都不会的秘技**——但极耗时间）

**流派系统**：拜师入门 → 学秘技 → 得**印可** → 可**创立流派 / 开设道场**；另有**踢馆**（胜则名声 +7/+13，败则 -1；踢馆会禁止进入该道场半年）、**收徒**（需有流派印，名声越高成功率越高）。

> **设计要点**：小游戏的真正作用不是"考验操作"，而是**给重复动作换皮**。修业要反复进行几十次，如果每次都是进度条，玩家会崩。这一条对我们极其重要——见 §10。

### 3.4 任务层（主命）

```
每奇数月 1–5 日 召开评定
   └→ 大名/城主发布【主命】或【合战】
        └→ 玩家在期限内执行（武士可自选主命；忍者不能自选）
             └→ 回城复命 → 【成果评价】（不是完成即满额，成果越大功勋越多）
                  └→ 逾期未完成即使完成也受斥责、扣功勋
```

**主命按身份分档解锁**（档位越高，功勋越多、越难）：

| 最低身份 | 代表主命 |
|---|---|
| 足轻组头 | 修业、买卖军事物资、人才调查 |
| 足轻大将 | 筹集军资金、训练、调查城 |
| 侍大将 | 提升治安、征兵、**破坏**、**谣言**、**放火** |
| 部将 | 开发新田、开发矿山、补修、外交朝廷、其他外交 |
| 家老 | 增筑、劝诱 |

> **这条阶梯是"权限解锁"的教科书式实现**：玩家身份每升一档，可接的主命种类变多、单条功勋变高。**成长 = 活儿变高级，不只是数字变大。**

### 3.5 身份层（武士 ladder）

| 身份 | 特征 |
|---|---|
| 足轻组头 | 最初级，只能接最简单的内政/购买型任务 |
| 足轻大将 | **可拥有自己的属下（陪臣）**、可劝诱浪人 |
| 侍大将 | — |
| 部将 | — |
| 家老 | — |
| **城主** | **自己开评定、给家臣下主命**；负责内政与军备；需筹措军资金 |
| **国主** | 支配多座城，可在自己城之间**自由输送物资** |
| **大名** | 谋反（城主/国主时于评定执行）或大名死亡后继任；可同盟、外交、委托商家/忍者众/水军众、与朝廷外交 |

**属下机制**：足轻大将以上可有属下，**属下俸禄从自己俸禄里分割**——身份低、俸禄少时养不起太多人。这是一个天然的"规模约束"。

### 3.6 关系层

| 机制 | 规则 |
|---|---|
| **亲密度** | 以"心"显示。送礼 / 茶席 / 交手（比武，需 1 心后）/ 反复拜访 提升 |
| **每月限制** | 对同一人物，**每月"送礼"与"茶席"只能二选一执行一次** |
| **茶席** | 武士收集人物卡的**主要手段**（既能涨亲密度又涨茶道经验） |
| **交手** | 亲密度 1 心后可比武提升 |
| 关系的用途 | 学技能（对方技能 > 自己且不拒绝）、**仕官**（需对象亲密度达标）、劝诱浪人/武将、获得**人物卡**、成为直臣 |

**仕官门槛的细节很有意思**：想见大名，要么名声 50、要么持有剑士/铁匠/医师/茶人的**三阶卡**（如"剑豪"）可**报上姓名**直接放行，要么贿赂 20 贯。→ **称号/职业成就是"通行证"，不只是数值。**

### 3.7 卡片层（元系统 —— 本作最重要的结构创新）

| 卡类 | 获取方式 | 作用 |
|---|---|---|
| **主人公卡（800）** | 与其他人物**亲近后**入手 | **该人物成为下次开局可选的主角** |
| **称号卡（63）** | 穷究某项术业 / 达成成就 | 直接加能力（武力/统率/智谋/政务/魅力 +3~15）、解锁行为（创立流派、开设道场、震慑山贼）、部分为"恶系"称号影响结局 |
| **秘技卡（70）** | 入门流派受教 / 名胜**冥想** | 个人战中作为秘技使用 |
| **合战特技卡（61）** | 技能修业中入手 | 合战中作为特技使用 |
| **名胜卡（32）** | 大地图上造访名胜 | 纯收集；集齐可得称号"漂泊旅人"；可冥想 |
| **其他卡（54）** | 修业或搭话时偶然获得 | 各种效果与职业相关 |

**卡片的跨周目规则（关键）**：
- **卡片效力仅止于获得该卡的存档**；重开新游戏，收集的卡失效（除主角卡）
- 满足特定条件后可**继承其他主角获得的卡**

**收集数量的元解锁（把收集本身变成进度条）**：

| 收集数 | 解锁 |
|---|---|
| 50 | 可自创新武将 |
| 100 | 开放 1568 / 1575 年剧本 |
| 200 | 开放 1582 / 1598 年剧本 |
| 300 | CG 鉴赏 |
| 400 | 迷你游戏可选 |
| 500 | 音乐鉴赏 |
| 800 | 可自行调整主人公数据 |
| 全卡 | 可调整所有武将数据 |

> **这是本次调研里对我们价值最高的单点**：太阁5 用一张"卡片收集表"解决了**长线动力**问题——玩家在单局之外还有一个永不满级的元目标，而**元目标的奖励是新的可玩内容**（新主角、新剧本）。这是"重玩即进度"的范例。

### 3.8 战斗层

| 层 | 内容 |
|---|---|
| **个人战** | 回合制，靠**气力值**驱动秘技；气力上限与剑术技能挂钩；装备的武器决定攻击模式与可用秘技（刀/枪/苦无/锁镰/铁炮/弓各有秘技体系） |
| **野战 / 攻城战** | 战棋式；按兵种消耗**技能点**使用合战卡（特技），技能点每回合恢复 1 点 |
| **水战** | 按船的大小分船军 / 大型船军 / 铁甲船军 |
| **忍者战** | 特殊兵种忍者军；潜入、城门爆破 |

**战斗口碑**：相对系列前作被**弱化**。攻城基本是"不断撞城门"，野战靠几个特定技能吃遍天——这是太阁5 被批评较多的一块。

### 3.9 经济层（San13 基本缺失，太阁的强项）

- **跑商**：町之间倒卖特产（茶、红花等），米相场各地不同，可低买高卖
- **副职业生产**：铁匠打造武器、茶人制作茶器、药师调和药品——**可做出比商店贵重品价值更高的作品**，且制作经验是隐藏经验值，越做越好
- **座 / 商馆 / 投资**：商人职业专属，开发特产品、商人司竞争
- **海外**：大型船可前往海外 4 都市
- **酒馆**：赌博（坐庄可无本起利）、雇佣打手

**经济的定位**：副职业是**主要财源**，也是武士路线拉关系的工具（茶席）。经济线让"不打仗也能玩"成立。

### 3.10 世界层

62 国 / 城 / **町**（市镇）/ **里**（忍者之里）/ **砦**（水军砦）；町内设施：马屋、锻冶屋、道场、商家、寺、南蛮寺、茶人宅、医师宅、米屋、酒馆、座。大地图上散布 **32 处名胜**（山 / 瀑布 / 湖 / 寺社 / 绝景五类）。

## 四、玩家行为拆解

### 4.1 时间结构

| 时钟 | 说明 |
|---|---|
| **一天四段** | 早 / 中 / 暮 / 晚（界面显示），移动与行动消耗时间 |
| **修业** | 一般一次 20 天 |
| **月** | 1 日发俸禄；对同一人每月只能送礼或茶席一次 |
| **每奇数月 1–5 日** | **评定**（强制到场，迟到扣功勋） |
| **主命期限** | 两次评定之间 |

### 4.2 典型行为清单（两次评定之间的一次循环）

1. 回城参加评定，领主命（或领合战）
2. 走到目标地点（数天）
3. 执行主命（修业 20 天 / 内政 / 调略 / 买卖……）
4. **利用剩余时间自由安排**：修业技能、跑商、茶席拉关系、拜访人物、采药、赌博
5. 回城复命，领功勋
6. 等待下一次评定

### 4.3 行为的四种驱动动机

| 动机 | 玩家在想什么 |
|---|---|
| **功勋驱动** | "这次要接个成果能翻倍的主命" |
| **技能驱动** | "还差 2 个技能没满，趁空档去修业" |
| **收集驱动** | "这个人的卡我还没有，去刷他亲密度" |
| **结局驱动** | "这局走剑豪还是走城主谋反" |

> **与 San13 的显著差异**：太阁5 的**"收集驱动"**是一个独立且长期存在的动机，且它**跨局有效**。San13 没有这一层。

## 五、成长路径（多维）

```
5 能力 ──决定上限──→ 16 技能（4 级 ──实战──→ 星级）
                        ↑
              修业小游戏 / 拜师 / 冥想

主命成果 ──→ 功勋 ──→ 武士阶级 ──→ 属下数 / 带兵数 / 主命档位
                                        └→ 城主 → 国主 → 大名（谋反/继承）

亲密度 ──→ 学技能 / 仕官 / 劝诱 / 【人物卡】

技能穷究 ──→ 称号卡 ──→ 能力加成 + 行为解锁（创派/开道场/报上姓名）
                    └→ 【元进度】收集数 ──→ 解锁新主角 / 新剧本 / 新功能

副职业经验 ──→ 更高质量的作品 ──→ 财源 + 社交工具
```

**四条线的关系**：
- **功勋线**：体制内晋升，出口是权力（城主/大名）
- **技能线**：个人能力，出口是"术业有专攻"的称号与流派
- **关系线**：社会资本，出口是人物卡与人才
- **收集线**：**元进度**，出口是下一局的可玩内容

**关键观察**：太阁5 的成长线比 San13 **多一层**——它有一条**跨局持久的元进度线**。前三条都随存档清空，第四条不会。

## 六、验证机制（做了什么会被承认）

| 验证对象 | 判据 | 奖励 | 惩罚 |
|---|---|---|---|
| **主命** | 期限内完成 + **成果评价**（成果越大功勋越多） | 功勋（按主命档位递增） | **逾期完成也受斥责、扣功勋** |
| **合战** | 战功；对军团/城门最后一击功勋更多；**自己部队被歼灭则战功减半** | 大量功勋 | 战功减半 |
| **修业** | 小游戏完成度 → 经验；**经验累积制**，失败也涨 | 技能等级 | — |
| **技能上限** | 能力值门槛（40/50/60/70） | 可修到的等级 | 达不到就修不上去 |
| **星级** | **只能靠反复使用**，修业无法达到 | 技能真满级 | — |
| **亲密度** | 每月一次上限的送礼/茶席 | 学技能、仕官、人物卡 | — |
| **称号** | 穷究术业 / 达成成就（如个人战胜利 10/20/50/100 场） | 能力加成 + 行为解锁 | — |
| **流派** | 拜师学全秘技 → 印可；踢馆胜负 | 名声 ± | 踢馆败则名声 -1、禁入半年 |
| **体力** | 修行/受伤降低，**最低 1**，越少越易生病 | — | 生病：能力难发挥、无法修行；需医师宅治疗 |
| **终局** | 统一 / 正一位 / 各职业"天下第一" / 结局分支（50+ 种） | 通关 + 结局 | — |

**观察**：
1. **"成果评价"而非"完成判定"**——与 San13 一致。这是两款游戏的共同选择，值得注意。
2. **修业是"经验累积制"**：即使一次都没成功，攒够次数也能升级。→ **它刻意降低了技巧门槛，避免卡住玩家**。这对我们做自动化是一个正面信号：**这类游戏的成长本来就不依赖操作精度**。
3. **体力/疾病是唯一的"负状态"系统**：不惩罚失败，只惩罚**过度投入**。

## 七、体验节奏

### 7.1 阶段划分（以武士线为主）

| 阶段 | 身份 | 主要在做什么 | 主导动机 | 爽点 | 痛点 |
|---|---|---|---|---|---|
| **① 浪人期** | 浪人 | 跑商赚钱、练满技能、刷人物关系 | 技能 + 收集 | 完全自由，无评定压力；**很多老玩家刻意停在这一阶段** | 无俸禄，起步慢 |
| **② 出仕初期** | 足轻组头～足轻大将 | 接低级主命、修业、拉关系 | 功勋 + 技能 | 第一次有属下 | 主命低级、功勋少 |
| **③ 中坚期** | 侍大将～部将 | 接调略/内政主命、参加合战 | 功勋 | 活儿变高级（破坏、放火、外交） | 评定期限压力大 |
| **④ 家老 / 城主期** | 家老 → 城主 | **自己开评定、给家臣下主命**、管内政与军备、筹措军资金 | 经营 + 布局 | 第一次"当老板"；培养家臣 | 责任变重，事务繁琐 |
| **⑤ 国主 / 大名期** | 国主 → 大名 | 谋反或继位，统一战争 | 统一 | 终局成就 | **后期拖沓**：几十座城纯体力活，机械分配粮草、点兵出征 |

### 7.2 阶段轮替规律

与 San13 高度一致——**每一阶段玩家的"可操作集合"变大一圈**：
获得编制 → 获得属下 → 获得城 → 获得天下。

但太阁5 多了一个 San13 没有的维度：**每一阶段都可以不推进**。玩家可以永远当浪人、永远当剑豪、永远经商。**"不晋升"是一种合法玩法**——这是它自由度口碑的来源，也是它节奏松散的来源。

### 7.3 节奏塌陷（三处）

| 塌陷 | 现象 | 归因 |
|---|---|---|
| **"38 天空档"** | 主命要 22 天（1 天去 + 20 天执行 + 1 天回），距下次评定还有 38 天；修业一次要 20 天，恰好不够两次；剩余十来天只能喝茶或睡觉 | **行动时长颗粒度与周期不匹配**。评定周期是刚性的，但填充手段的时长是固定的，产生无法消化的余数 |
| **后期拖沓** | 天下大势已定后，几十座城变成机械操作 | **缺少"优势方抑制"与"终局加速"机制**（与 San13 同源问题） |
| **割裂感** | "小游戏比内政外交还多，来回点点点" | **表现形式过杂**：每一类动作都有独立小游戏，玩家在不同交互模式间反复切换 |

> **"38 天空档"这一条对本项目是正面素材**：这类游戏最难处理的是"周期性刚性节点之间的自由时间"。**而我们的产品恰恰是围绕"填满移动时间"设计的**——V1 已实测赶路占 91% 时长。太阁5 的玩家可以睡觉跳过，我们的玩家可以关掉页面。这是我们的机会窗口。

## 八、设计得失（口碑）

### 8.1 做对的部分

| 项 | 说明 |
|---|---|
| **跨周目卡片收集** | 把重玩变成进度，长线动力极强，是系列口碑支柱 |
| **技能成长 = 小游戏** | 把重复动作换皮，"避免枯燥刷级"（正面评价） |
| **职业 + 副职业的搭配** | 主副职业组合带来充足重玩动力 |
| **自由度高且不设终点** | 可不当武士、可不晋升、可颠覆历史 |
| **勋章式的称号卡** | 直接加能力 + 解锁行为 + 可作通行证，三层价值 |
| **冥想** | 给出一条"师父也不会的秘技"的意外路径，制造惊喜 |

### 8.2 被批评的部分（设计层归因）

| 项 | 归因 |
|---|---|
| 后期拖沓 | 无终局加速机制；优势方无抑制 |
| 剑豪/茶人/铁匠/医师完成度低 | **副职业只有"重复操作 → 天下第一"一条路径**，缺少中段内容 |
| 战斗系统弱化 | 攻城=撞城门，野战靠固定技能 → 战斗层没有吃到设计预算 |
| 人物属性成长极难 | 能力值难涨，"基本固定几个猛人" → 成长反馈弱于收集反馈 |
| 小游戏过多导致割裂 | 表现形式缺乏统一节奏 |
| 事件触发依赖攻略 | 收集型内容的**可发现性**设计缺失 |
| DX 重制"没诚意" | 暴力移植，未解决老问题（慢、UI、检索） |

## 九、内容供给方式

| 供给源 | 规模 | 特性 |
|---|---|---|
| 人物 | 860 名 | 铺量；个体差异靠能力 + 技能 + 事件 |
| 卡片 | 1080 张（DX） | **收集即内容**，跨局持久 |
| 剧本 / 章 | 1554 乱麻 / 1560 日轮 / 1568 升龙 / 1575 霸道 / 1582 转变 / 1598 太平 | 多时间点，靠收集解锁 |
| 历史事件 | 桶狭间、本能寺、清州会议、贱岳、大坂城建成等 | 高成本高感知，且**玩家可参与并改写** |
| 结局 | 50+ 种 | 每条职业线 + 副职业线各有结局 |
| 名胜 | 32 处真实景点 | 纯收集，附带地理知识 |
| **事件编辑器** | 可自制事件 | UGC 兜底 |

**对比 San13**：太阁5 的内容更依赖**"收集"这一行为本身**，而不是内容的叙事质量。人物卡 800 张里大部分是"大众脸"，被批评"复制粘贴、没收集欲望"——**这说明铺量型收集有边际效用递减**。

## 十、对「闲逛」V2 的初步判断（详细交叉见对比文档）

| 太阁5 元素 | 我方判断 |
|---|---|
| **跨周目元进度（卡片收集）** | **强烈建议引入**。这是长线动力最便宜的解法，且天然适配我们的"人物收集"方向 |
| **技能成长 = 小游戏** | **不能直接要**（小游戏需要在线操作），但**原理必须保留**：重复动作必须换皮，否则我们的自动任务就是纯进度条 |
| **个人经济线（跑商/副职业）** | **高度适配**。跑商 = 我们 V1 已有的"城市间移动 + 物品"，只需把物品语义从"材料"改成"货物/礼品" |
| **职业赛道（武士/忍者/商人…）** | 可作为中长期目标，但要吸取教训：**每条赛道都需要中段内容**，不能只有"重复操作 → 天下第一" |
| **冥想式惊喜路径** | 值得抄：给成长留一条"意外获得"的口子，制造惊喜 |
| **称号 = 能力 + 行为 + 通行证三层价值** | 值得抄：让里程碑同时具备三种价值，性价比最高 |
| **"38 天空档"** | **这是我们的机会**：这类游戏处理不好自由时间，我们恰恰是围绕它设计的 |
