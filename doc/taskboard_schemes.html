任务板 · ABC 两类信息方案对照

目标：按 A 采集 / B 制造 / C 人物 调整卡片信息，保持视觉一致性，同时把每类的「关键信息」表达清楚。
三类关键信息差异：A=材料产量｜B=成品+需要图纸状态｜C=好感对象+稀有材料+需要图纸进度。

A 采集 B 制造 C 人物

方案 1 · 统一骨架 + 类别色编码 色统型

所有卡片用同一套骨架（标题 / 关键行 / 进度条），唯一差异是左侧类别色条 + 类别角标。
关键行按类切换内容，但排版统一（左灰标签 + 右亮值）。改动最小、屏效最稳、一致性最强。

⚠ 取舍：C 类的「好感对象 + 稀有 + 需要图纸%」被压成一行，信息偏挤；想看"离需要图纸还差多少"只能靠百分比文字。

方案 2 · 类别专属字段区 结构化型

卡片外壳仍统一，但第二行变成结构化字段块：用统一的「标签芯片 + 值」语法渲染，
字段集合按类不同，但每个字段画法完全一致 → 视觉仍统一，信息密度更高。
