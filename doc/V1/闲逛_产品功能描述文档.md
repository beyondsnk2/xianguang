## 一、产品概述

### 1.1 一句话定位

**三国题材的地图挂机游戏**：玩家的角色在一张大地图上自动行走，按任务列表逐个前往各地完成任务，
攒资源、涨属性、练技能；玩家不操作时游戏照常运转，在线只是为了做决策和看表现。

### 1.2 平台与形态

| 项 | 第一版 | 终极形态 |
|---|---|---|
| 平台 | PC 网页（单页） | PC + 手机网页 |
| 运行方式 | **纯前端**，无服务端 | 服务端 MMO |
| 存档 | 浏览器本地（localStorage） | 服务端权威存档 |
| 商业化 | **不做** | 待定 |
| 多人 | 无 | 同屏 MMO |

### 1.3 题材包装

三国。大地图划分为多个区域（终极形态为十三州），每个区域有自己的特色物产与任务倾向——
例如西凉多剿匪、司隶多挖矿、扬州多打渔。**第一版先做 4 座城**（上庸 / 新野 / 永安 / 襄阳），
不建"州"这一层。

### 1.4 差异化（与市面同类产品的区别）

核心特征五条：**① 大地图真实移动 ② 随机任务驱动行为 ③ 背包容量→银行往返
④ 技能影响任务生成 ⑤ 属性影响任务产出**。

市面上没有热门产品同时具备这五条（详见 `挂机游戏竞品分析.md`）：
Legends of Idleon 有真实移动与属性影响产出但无随机任务；Melvor Idle 有完整的技能-产出-银行
数值骨架但没有地图。本产品落在这两者之间的空档。

## 二、核心体验目标

| 目标 | 说明 |
|---|---|
| **挂机友好** | 不操作也能拿到约 80% 的收益，精细操作最多 120%。绝不惩罚不操作的人 |
| **在线是决策窗口，不是产出窗口** | 在线与离线的资源 / 经验 / 属性**完全一致**；在线的额外价值只有"决策 + 观察" |
| **看得见的成长** | 角色真的在地图上走；移速提升 = 活动范围可见地扩大 |
| **单次上线几分钟** | 参考 AFK Journey 的好评命脉：五分钟清完日常，不绑架时间 |
| **物流是策略层，不是打扰** | 回城全自动；玩家的乐趣从"做不做"转向"**怎么做更快**" |

## 三、核心循环

### 3.1 主循环（全自动，玩家零操作）

```
任务板刷出任务 → 角色自动沿路走到目标设施 → 执行（needTime）→ 结算
     → 背包满了？→ 是：自动回州府存入仓库、清空背包
     → 取下一个任务，循环
```

**这一段全程不需要玩家点任何东西**，离线时同样在跑。

### 3.2 玩家的三项核心操作

| # | 操作 | 本质 | 说明 |
|---|---|---|---|
| ① | **拖动任务排序** | 小型旅行商问题（TSP） | 本作最具辨识度的操作。改变顺序 = 减少赶路时间 |
| ② | **调整装备 / 专精** | 调节任务刷出的概率与稀有度 | 决定"我想多刷哪类任务" |
| ③ | **处理随机事件列表** | 在线专属的二选一 / 小游戏 | NPC 提问、武将切磋等 |

**取消任务是低频操作**：24 小时完成约 130 个任务，最多只能刷掉 12 个左右。

### 3.3 一轮任务的时长结构

按第一版数值（`speed = 20` 秒/格，`needTime = 60` 秒）：

| 阶段 | 时长 | 占比 |
|---|---|---|
| 赶路（平均 29.9 格） | 599 秒 | 91% |
| 作业 | 60 秒 | 9% |
| **单任务周期** | **约 660 秒 ≈ 11 分钟** | — |

> **作业时长相对赶路几乎可忽略。这个游戏的时间几乎全花在路上。**
> 因此所有数值调优都应围绕"移动"，而不是 `needTime`。

## 四、功能详解

### 4.1 地图与移动

| 项 | 取值 |
|---|---|
| 逻辑尺寸 | 36 × 30 格 |
| 单格 | 30 像素（画布 1080 × 900） |
| 坐标系 | `X:Y`，X 向右，Y 向下 |
| 节点占地 | 州府 2×2 = 4 格，其余设施 1 格 |
| 移动速度 | `speed = 20` **秒/格** |

- **单张连续地图**，不做"区域图 / 大地图"双层切换（会打断"看着小人走"的表现），
  改用自由缩放。
- **节点显示**：州府 2×2 显示**全称**（上庸 / 新野 / 永安 / 襄阳），单格设施只显示名称**首字**
  （兵 / 市 / 田 / 酒 / 书 / 矿）；多格节点整块填充，**块内不画网格线**；文字居中于格子。
- 角色**沿道路格逐格移动**，不能斜穿空地。
- 移动完全自动寻路，玩家不操控。

**地图数据（第一版）**：4 座城，每城 1 个州府（2×2）+ 3 个设施，共 **16 个节点**；
道路格 **80 个**。

| 城市 | 州府 | 设施 |
|---|---|---|
| 上庸 shangyong | 1 city | 2 兵营 / 3 街市 / 4 农田 |
| 新野 xinye | 5 city | 6 酒馆 / 7 农田 / 8 矿山 |
| 永安 yongan | 9 city | 10 街市 / 11 兵营 / 12 书院 |
| 襄阳 xiangyang | 13 city | 14 矿山 / 15 酒馆 / 16 书院 |

> **新野是有意保留的偏远州**：它只有一条出路回上庸，到其他城最远（55 格）。
> 这构成地图的距离梯度，是"远州高价值 / 长途物流成本"设计意图的载体。

### 4.2 任务系统

**任务内容**：「去 XX 城市做 XX」。

六类任务，每类恰好分布在 2 座城，共 12 个任务点位：

| task.tag | 名称 | 设施 | 城市 | 作业时长 | 产出 |
|---|---|---|---|---|---|
| `train` | 训练 | 兵营 barrack | 上庸、永安 | 60 s | 武力经验 10–20 |
| `trade` | 交易 | 街市 market | 上庸、永安 | 60 s | 政治经验 10–20 |
| `farming` | 种植 | 农田 farmland | 上庸、新野 | 60 s | **粮 grain × 5–7** |
| `banquet` | 宴会 | 酒馆 tavern | 新野、襄阳 | 60 s | 统帅经验 10–20 |
| `read` | 读书 | 书院 academy | 永安、襄阳 | 60 s | 智力经验 10–20 |
| `mining` | 采矿 | 矿山 mine | 新野、襄阳 | 60 s | **矿 mine × 2–4** |

**任务板规则**：

| 项 | 规则 |
|---|---|
| 槽位数 | `initTaskListSlot = 7` |
| 补位 | 完成一个 → **该任务出列、后续任务整体上移、空槽移到队尾** → **独立计时 180 秒** → 新任务补在任务区末尾（空槽之前） |
| 开局 | **列表直接给满**，否则第一个任务要干等 3 分钟 |
| 有效期 TTL | **没有**。任务永不过期 |
| 拖动 | 只能拖"待执行"的；**成为队首（开始移动）即锁定**；拖完归位后空槽仍在队尾 |
| 取消 | 低频，24 小时约 12 次额度（详见开发文档） |

> **为什么不需要 TTL**：执行全自动 + 玩家最终要练满所有技能线，因此不存在"废任务"，
> 不想要的任务放着也会被执行掉，不会堵死任务板。

**任务生成**：第一版**等概率**从 6 类中选 1 类 → 从支持该类的 2 座城中选 1 座 → 定位到该城的设施节点。
（技能 / 装备 / 专精对概率的影响**后置到 V2**，见第八节）

### 4.3 背包与仓库

| 项 | 取值 |
|---|---|
| 背包格数 | `backPackSlotNum = 6` |
| 单格堆叠 | `itemStacking = 5` |
| **总容量** | **30 个物品** |
| 仓库 | **全局共享**，从任何州府存入的都是同一池子 |

**超载规则**：

1. **正在执行的任务产出必定完整入包**——不截断、不丢弃。做完后再判断是否超容。
   （避免出现"装了一半"这种说不清的中间态）
2. 超容 → 系统**自动**插入"回最近州府 → 全部入仓 → 清空背包 → 继续下一个任务"。
3. 回城**全程自动**，不需要玩家点击。

**回城频率**：粮（均值 6）约 5 次装满、矿（均值 3）约 10 次装满；产出型任务占 6 类中的 2 类，
综合约每 15–30 个总任务回城一次 → **约 4–9 次/天**。

> ⚠ **一个值得注意的实测结论**：每个设施到本州州府的距离**恰好都是 3 格**，
> 因此一次回城的额外路程平均只有 **0.86 格（17 秒）**——回城成本极低，几乎顺路。
> 好处是完全不打断挂机；代价是"背包压力"的存在感很弱。
> 若将来想要强化物流玩法，需要让存放点更远或限制跨州存取。

### 4.4 角色成长

**四维属性**：武力 force / 统帅 leadership / 智力 intelligent / 政治 politics，初始各 `2–5` 随机。

| 项 | 规则 |
|---|---|
| 升级曲线 | `attrLv` 表，1–120 级，本级升下一级所需经验 6 → 480 |
| 获取方式 | 完成任务获得对应属性经验 |
| 作用 | 影响任务产出量（如力量高 → 挖矿产出多） |

**技能**（V2 落地，第一版只预留）：

- 技能影响**任务刷出的概率与稀有度**（如挖矿等级高 → 更容易刷出挖矿任务，且有概率刷出秘银矿替代铁矿）
- 移动分**两层技能**：第一层加速区域内移动，第二层加速大地图跨区移动
- 成长曲线类似**对数函数**，但必须有**渐进下限**（不低于原耗时 25–30%）+ **离散里程碑**
  （官道 / 渡口 / 坐骑，每解锁一个画面有变化），否则纯粹的对数曲线体感是"越升越没感觉"

> ⚠ **技能职责必须解耦**（详见 `闲逛_关键机制可行性分析.md` 第四节）：
> 技能等级管"**有多强**"（产出能力、解锁门槛），装备 / 工具 / 倾向管"**刷什么**"（任务概率偏好）。
> **绝不能让玩家产生"我想把自己的技能等级降下来"的念头**——若有这种需求，说明职责耦合错了。

### 4.5 在线与离线

**核心承诺：在线与离线的资源 / 经验 / 属性完全一致。**

| 维度 | 在线 | 离线 |
|---|---|---|
| 资源 / 经验 / 属性 | 一致 | 一致 |
| 任务执行、回城存仓 | 自动进行 | 自动进行 |
| 编排队列、换装备、改倾向、取消任务 | 可操作 | 按上次设定自动跑 |
| 随机事件 | 可处理 | 只积累，不自动处理 |
| 观察型收集（旅途日志、风景图鉴） | 在线专属 | 不产出 |

- **离线收益基于本地时间戳**计算（第一版不防作弊，终极形态以服务器时间为准）
- **离线收益上限 8–12 小时**（既是限损也是品类惯例）
- 离线结算用离散事件推进，不是逐秒 tick（详见开发文档）

### 4.6 随机事件

挂机过程中会积累需要玩家在线处理的事件（NPC 提问二选一、武将切磋小游戏等）。

| 项 | 规则 |
|---|---|
| 过期 | **永不过期** |
| 上限 | 同时最多 8–12 个未处理，**满了就停止生成** |
| 提示 | 满载前必须在界面明显提示（徽标 + 首次满载一次性说明） |
| 便利 | 支持"**一键全部按默认处理**" |

> **红线**：在线专属内容必须**非数值、非进度**。二选一可以给"总量期望相同但结构不同"
> （100 铁 vs 50 铁 + 1 稀有料），**但不能给额外资源效率**，否则违背在线离线一致的承诺。

## 五、已确认的设计决策（不可推翻）

| # | 决策 | 理由 |
|---|---|---|
| 1 | 任务执行与回城**全部自动** | 否则离线时角色卡在"等回城"，离线收益归零 |
| 2 | **不设任务 TTL** | 全自动 + 全技能线都要练 → 不存在废任务 |
| 3 | 第一版**单角色**，可练满所有技能线 | — |
| 4 | **强制跨州依赖**（顶级配方需七八州独占材料） | 否则多区域会退化成单区域，第二层移速技能变死技能 |
| 5 | **仓库全局共享** | 否则"我的粮在永安、人在襄阳"是纯粹的游戏性灾难 |
| 6 | 在线离线收益**完全一致** | 挂机品类天条 |
| 7 | 第一版**不做商业化** | — |
| 8 | 任务**必定成功** | 保证离线结算的确定性；失败机制后置（战斗只是皮肤） |
| 9 | **单张连续地图**，不做双层切换 | 保住"看着小人走"的表现 |
| 10 | 新野**保持偏远，不补路** | 有意保留的距离梯度 |
| 11 | 洗点 / 换配置**免费或极低代价** | 既然要练满所有技能，倾向只是节奏工具，锁死只会带来选错焦虑 |
| 12 | 第一版**不建"州"层** | 只有 city → mapNode 两层 |

## 七、数值基线（V1 验收参考）

| 指标 | 数值 |
|---|---|
| 移动速度 | 20 秒/格 |
| 期望单程（任务点之间） | 29.93 格 ≈ 599 秒 |
| **单任务周期** | **约 660 秒 ≈ 11 分钟** |
| **24 小时任务量** | **约 131 个**（目标 120 个/天，在同一量级） |
| 同城连做周期（玩家精排后） | 约 148 秒 |
| 最远单程（新野酒馆 ↔ 襄阳矿山） | 55 格 ≈ 18.3 分钟 |
| 回城频率 | 约 4–9 次/天 |
| 一次回城的额外成本 | 0.86 格 ≈ 17 秒 |
| 任务板稳态空槽 | 0.27（默认）/ 1.21（玩家精排后） |
| 背包总容量 | 30 个物品 |

> 抽干 7 个槽需要单任务周期 < 25.7 秒，而 `needTime = 60` 已远超，
> **因此角色永远不会空转** ✅

**实现后实测（2026-10-01，24 小时离线模拟）**：

| 指标 | 基线 | 实测 |
|---|---|---|
| 24h 任务量 | ≈ 131 | 125（8 个随机种子均值 **130.8**） |
| 单任务周期 | ≈ 660 s | 691 s |
| 回城次数 | 4–9 | 7 |
| 稳态空槽 | 0.27 | 0.26 |
| 角色空转 | 永不发生 | **0 次 / 2880 次采样** |
| 超容却未回城 | 0 | **0** |

> 路网 5 项基准（6 / 22 / 31 / 37 / 55 格）与 96 点 97 边全部命中，
> 详见 `闲逛_初期最简流程_v1.md` 第九节。

## 八、后续版本规划

| 版本 | 主题 | 关键内容 |
|---|---|---|
| **V2** | 让选择有意义 | 技能系统（概率 / 稀有度）、装备与专精、移速两层成长与活动半径、道具合成与跨州集料、随机事件 |
| **V3** | 内容与规模 | 扩到十三州、州层与大地图第二层移动、驻所 / 坐骑、更多任务类型与道具 |
| **终极** | MMO | 服务端权威时间与存档、多人同屏、手机网页、商业化 |

**V2 必须注意的梯度问题**：跨州依赖要**逐步加深**（早期配方只跨 2–3 州，逐步到 7–8 州）。
一步到位会让前期体验非常卡顿——第二层移速还没练起来时，每次做任务都跨州就像惩罚。
