## 一、配置表 schema（`config/firstShow_V4.xlsx`）

### classDefs
| 列 | 类型 | 说明 |
| --- | --- | --- |
| classType | str | 主键（youxia…moushi） |
| name | str | 中文名 |
| promoteCond | str\|null | `classPromoteCond.condId`；`;` 分隔多条件（V1 单条件） |
| rankCount | num | 阶数，默认 9 |
| note | str | 备注（含亲密度速记） |

### classAffinity
`classType` / `skill` / `aff`(`main`\|`sub`)。路由偏置层；`main`=★ 强偏置，`sub`=◐ 弱偏置。

### classPromoteCond
`condId` / `type` / `target` / `threshold` / `note`。四型：
- `a_rep` → target=技能 tag，threshold=技能 Lv
- `b_general` → target=武将 tag 或 `'any'`，threshold=好感值
- `c_standing` → target=身份 tag（threshold 忽略）
- `d_train` → target=属性 key 或 `'totalSkillLv'`，threshold=值

### classEffect
`classType` / `rank`(1..rankCount) / `effectKey`(`gatherYield`\|`craftSave`\|`socialFavor`\|`attr*`) / `value` / `note`。按 `rank ≤ 当前阶` 累加取值。

### standingDefs
`standingTag` / `name` / `reqClasses`(`classType:lv;` 分隔) / `reqStandings`(前置身份 `;` 分隔) / `note`。

### config 开关（config 表 `tag→content`）
`classUnlockSkillLvTotal=10` / `classSkillWeight=4` / `classSwitchCdSec=3600` / `classSlotBase=1` / `classSlotStep=3` / `classExpPerQuality=3`。缺列回落默认值（见 `parse.ts` 内 `asNum` 兜底）。

## 二、核心 API（`src/game/classSystem.ts`）

| 函数 | 行为 |
| --- | --- |
| `totalSkillLv(state)` | Σ 全部技能等级 |
| `isClassUnlocked(state,cfg)` | `totalSkillLv > values.classUnlockSkillLvTotal` |
| `condMet(state,cond)` | 单条晋身条件是否满足 |
| `getUnlockedClasses(state,cfg)` | 已晋身职业线（`promoteCond` 内 condId 全满足） |
| `isClassLineUnlocked(state,cfg,classType)` | 某线是否已晋身 |
| `classAffinitySkills(cfg,classType)` | 该职业亲密度技能集合 |
| `prefSkillTags(state,cfg)` | 生效职业亲密度技能；未解锁 / 未选 → `[]` |
| `gainClassExp(state,cfg,skillTag,amount)` | 仅命中生效职业亲密度才涨；复用 `attrLvNeed` 晋阶；`emitEvent('class')` |
| `classEffectValue(state,cfg,key,fallback)` | 生效职业某键累计值（rank ≤ 当前阶求和） |
| `affClassEffect(state,cfg,skillTag,key)` | 命中亲密度才返回累计值，否则 0（门控） |
| `canSwitchClass(state,cfg,nowMs)` | `{ok, reason}` |
| `setActiveClass(state,cfg,classType,nowMs)` | 校验晋身 + 冷却；成功写 `activeClass` 并起冷却 |
| `activeStandingSlots(state,cfg)` | `base + floor(ΣclassLv / step)` |
| `standingReqMet(state,s)` | 职业阶达标 + 前置身份已上阵 |
| `syncStandings(state,cfg)` | 自动上阵满足需求的身份（仅增）；`emitEvent('standing')` |
| `classProgress(state,cfg,classType)` | `{rank, exp, need}` |

## 三、集成点（调用处与行为）

1. **`taskGen.ts` `pickTaskDef`**：职业解锁且 `activeClass` 非空 → `pref = classAffinitySkills`，权重取 `classSkillWeight`(4)；否则回退 `AMBITION_SKILLS[state.ambition]`（`free`→等权）。
2. **`tick.ts` 结算后**：若 `def.skill` → `gainClassExp(state, cfg, def.skill, classExpPerQuality × max(1, quality))`；随后 `syncStandings(state, cfg)`（晋阶即时判定身份解锁，不可降级）。
3. **`produce.ts` `settleGather`**：`mul = 1 + affClassEffect(state, cfg, def.skill, 'gatherYield')` 作用于 A 产量。
4. **`produce.ts` `settleCraft`**：`save = (EFF_SAVE_AT_BEST(0.25) + affClassEffect(def.skill, 'craftSave')) * clamp(ev.mult - 1, 0, 1)`（省料上限 25% + 职业加成）。
5. **`produce.ts` `settleSocial`**：`favor = (FAVOR_PER_TASK(1) + max(0, q) + ev.tier) * (1 + affClassEffect(def.skill, 'socialFavor'))`。
6. **`state.ts`**：`createInitialState` 初始化 5 字段（`activeClass:null` / `classLv:{}` / `classExp:{}` / `classSwitchCd:null` / `standingActive:[]`）；`ensureRuntimeFields` 补齐这 5 字段 + 调 `syncStandings`。
7. **`events.ts`**：`EventKind` 增加 `'class'` / `'standing'`。
8. **`panels.ts` `renderCharacter` → `renderClassSection`**：职业段（解锁进度 / 各线阶·经验·亲密度 / 生效职业 `<select id="class-select">` + 冷却）+ 身份段（需求 / 上阵）。
9. **`main.ts` modalBody 监听 `class-select`**：空值清 `activeClass`；否则 `setActiveClass`（失败 `pushLog` 原因）；`renderModal(true); refreshUI()`。

## 四、路由规则（关键不变量）

- 职业解锁前（`totalSkillLv ≤ 10`）→ 任务偏置回退 `ambition`，`classEffect` 全不生效（`activeClass === null`）。
- 解锁后必须选 `activeClass` 才生效；多线解锁可切换，受冷却限制。
- **亲密度门控**：效果 / 经验只对「生效职业的亲密度技能」生效；非亲密度技能任务照常但不触发职业加成。
