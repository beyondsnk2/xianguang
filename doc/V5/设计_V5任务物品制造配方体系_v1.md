## 一、任务系统（ABC 三类的分工与生成）

### 1.1 三类分工（定案：版本二「演义奇工」）

| 类 | 定位 | 提供什么 | 主属性 | 类比 |
| --- | --- | --- | --- | --- |
| **A 采集** | 广度 | 基础材料（地图各处分布） | 武力 | 供应链上游（量） |
| **B 制造** | 深度 | 消耗材料 → 成品/消耗品/跑商道具 | 智力 | 供应链下游（效率） |
| **C 人物** | 机会 | 关系 + 稀有料 + 图纸 + 名品 | 政治 | 非物资线（质 / 前置） |

> 9 技能 = A3（采掘/采药/猎奇）+ B3（锻造/丹鼎/机巧）+ C3（访道/结义/出使），每技能独立 100 级 / 10 档。

### 1.2 任务生成（`taskGen.ts`）

```
抽技能（抱负加权）→ 该技能档位对应的 3 品窗口内加权抽品质 → 抽一座有该设施的城市
```

| 环节 | 规则 |
| --- | --- |
| 技能窗口 | `skillTier(lv)` 1–10；窗口宽 3，`min(tier,7)` 起，8 档触顶 7–9 |
| 品质权重 | 窗口内低/中/高 = `[50,35,15]`（tier1）→ `[20,30,50]`（tier≥8）线性插值 |
| 抱负加权 | 偏好技能权重 ×4（约 2/3 任务落在抱负集合）；`free` 全平等 |
| 节奏偏移 | `steady -1 / mid 0 / bold +1`，钳 [1,9]，不绑死抱负 |
| **B 过滤** | 只保留「本品质有已解锁物品族」的任务；全被图纸卡住 → 回退该技能 q≤3 初段（不空转） |
| **C 过滤** | 仅 `quality >= C_MIN_QUALITY(4)` 进池；过滤后空则该技能本期无 C 候选（不回退 q<4） |

**任务实例（`Task`）携带的运行时字段**
- `outputTag?`：B 类刷出时锁定的成品（已解锁族中随机），所见即所得
- `heroTag?`：C 类 10% 命中锁定的好感对象武将
- `rareTag?`：C 类（q≥4）锁定的具体稀有料物品 tag（如 `zhusha_5`）

### 1.3 任务板（`taskList.ts` · 结构化字段）

每张卡片 = `task-head（类别角标 + 标题 + 右侧状态）` + `task-fields（标签芯片块）` + `task-progress`，左侧类别色条（A 绿 / B 蓝 / C 紫）。芯片语法统一，三类视觉一致。

| 类 | 奖励芯片（按真实条件显隐） |
| --- | --- |
| **A 采集** | `产出 铁石 ×5~7 · 品n`（材料名+产量区间+品质合并为单底框；标题已含材料名，不重复） |
| **B 制造** | `成品 X`(hot) + 门槛层 `图纸 ✔/缺图` `主料 ×K ✔/补/缺` `主稀 ✔/缺`（红=卡住零产出，主稀永不自动买=真卡点）+ 加成层 `额外料 ×K ✔/补/缺` `额外稀 ✔/缺`（中性=少产不拦工）+ `耗金 N文`(金框，仅自动补货时) |
| **C 人物** | （仅 10% 命中）`好感度`（不透露武将）+（q≥4）`稀有 朱砂 ×1~4` + `图纸`（仅门槛满足时显"有机会"） |

> **底框一致性**：所有奖励芯片统一带可见边框（基础边框由 `var(--line)` 提亮为 `#444c5c`）。修复前普通品质（q1-3）的芯片边框在深底上对比过低、几乎看不见，导致 B 类「成品」芯片（仅挂 rarity、无 mod）显"无底框"；现在 A/B/C 各品质均显框。稀有度仍由 inset 内框+底色表达，mod 仍由 hot/warn/ok 边框色表达，三者互不冲突。A「产出」/ B「成品」/ C「好感度」主芯片均挂 `hot`（=各自类别色），三类主产出边框对称（绿/蓝/紫）。

> **诚实化原则**（反复修正后）：奖励区只放「完成该任务的真实产出 / 可行动状态」，不放配置元信息（`配方 基础/高阶` 已移除）。
> - 好感度：仅 heroTag 存在才显示类别标签，**不写具体武将名**（谁的好感在生成时即已锁定，但结算前对玩家保密，保留发现感）
> - 稀有：仅 rareTag 存在（q≥4）才显示（避免 q<4 不产稀有的误导）
> - 图纸：仅当「图纸门槛」全部满足（q≥4 ∧ 全局 favor≥30 ∧ 该技能有未拥有图）才显示，评价≥佳为结算判定故仅表"有机会"（不承诺必得，杜绝恒显误导）

> **B 类分层显示（2026-10-09 落地）**：B=制造，配方分两层，面板分层回答「材料齐备吗」「有额外料吗」——
> - **门槛层**（缺则零产出，红色 warn 提示）：`图纸`(仅高阶有) / `主料 ×K`(needItem1，库存≥K 才 ✔) / `主稀`(needRare，库存≥1 才 ✔)。任意一项缺→本次结算零产出。
> - **加成层**（缺则少产、不拦开工，中性提示不加红）：`额外料 ×K`(needItem2) / `额外稀`(needRare2)。齐备→多产 `cycles × EXTRA_BONUS_RATIO` 件；缺→只产基础层，不报错。
> - 齐备判定口径：`库存 ≥ 每件需求`（≥1 件即可开工），与结算按掷骰量消耗一致地取下限；精确产能受评价省料(上限25%)/掷骰量影响，面板不预演。
> - 旧版错标修复：原「缺图」分支下挂 `缺 <稀有料名>` 语义错位（缺图时本用不到料），已改为按层独立显隐，门槛/加成分开提示。
> - **E3 自动补货（2026-10-09 落地，最终口径「解耦」）**：主料/额外料不够时，结算自动用金币补足——**仅材料**（红线⑦ 不补稀有）。**解耦口径（用户 2026-10-09 改口）**：主料自身「全有或全无」——金币够买主料全部缺口才一次买入、否则照饿死零产出；额外料**独立判断**，仅在主料已凑齐(`matSecured`)且金币够买额外料缺口时才买，**买不起则跳过 bonus 不拦工**（少产不报错，开工不卡）。主稀/额外稀是稀有，永不自动买（主稀缺=真卡点）。面板同步：金币够补主料→主料显「补」(ok 绿)；金币够补额外料→额外料显「补」(ok 绿)；仅当实际发生补货时标 `耗金 N文`(金框，=主料补+额外料补实付之和)；金币不够补主料→主料维持「缺」(warn)且不显额外料信息（因造不出，bonus 信息无意义）。单价=`buyPrice`(基准价×城际系数×1.5溢价，`BUY_PREMIUM`)，面板金价=实际支出（按名义缺口买，评价省料余量归背包）。统计 `state.stats.restockCount`/`moneySpent` 接入。

**稀有度染色**：芯片按任务品质上色——`r-common`(q1-3 素净) / `r-rare`(q4-6 青底+内框，独立色 `--rar-rare`) / `r-legend`(q7-9 玫红底+内框，独立色 `--rar-legend`)，用 inset 内框不占 warn/ok 边框色。

> **配色三通道去冲突（2026-10-08 落地）**：颜色拆为正交三条通道，互不借用色相，消除旧版「一色多义」——
> 1. **类别通道**（卡片框 + 角标）：A 绿 / B 蓝 / C 紫(`--r1`) / 激活金(`--gold`)。稀有度**不再**借用 C 紫(`--r1`) 与 激活金(`--r2`)。
> 2. **稀有度通道**（芯片 inset 内框 + 淡底）：普通素净 / 稀有青(`--rar-rare #36c2d6`) / 传说玫红(`--rar-legend #d95fa8`) —— 全新独立色相。
> 3. **状态通道**（芯片边框 + 文字 mod）：`hot`=类色（A 产出 / B 成品 / C 好感度 现均挂 `hot`，三类对称）/ `warn`=红(缺) / `ok`=绿(可)。
> 旧冲突点：紫(=C类)曾同时是稀有档内框色；金(=激活)曾同时是传说档色；`hot` 旧版仅 C「好感度」生效、A/B 主芯片无类色边框 → 三者不对称。现三处均已消解。

### 1.4 评价四档 + 属性调制

| 档 | 名 | 增量（evalInc） | 乘率（波动外置） |
| --- | --- | --- | --- |
| 0 | 拙 | 0.0 | ×1.0 |
| 1 | 平 | 0.3 | ×1.3 |
| 2 | 佳 | 0.6 | ×1.6 |
| 3 | 绝 | 1.0 | ×2.0 |

- **保底 1×**，永不倒扣；技能经验不受评价影响。
- **属性调制**：`r = 属性值 / attrBaseline`，`attrBaseline = int(品质×4)`；A←武力 / B←智力 / C←政治，统帅作节拍器（30% 概率额外展示）。属性只移概率，不动保底/封顶。
- **三类同品质收益必须不同**：A 给量、B 给效率（省料）、C 给关系。

### 1.5 任务槽与空槽补位

- 任务板 `initTaskListSlot` 个槽，每槽 `empty`（独立补位倒计时 `REFILL_SEC=180s`）或 `task`。
- 当前任务 `locked`，其余 `draggable`（玩家仅拖顺序，少跑路）。

## 二、物品体系（四类）

`ItemDef.cat` ∈ {材料, 稀有, 成品, 名品}。V2 目标规模：**材料 27 / 稀有 54 / 成品 315 / 名品 3**（实际以 `firstShow_V4.xlsx` 为准）。

### 2.1 材料（A 产出 · 同名三阶）
7 种普通料（铁/铜/玉/草/异草/皮/野味），每种 3 阶（普通/上等/精制），**当量 1/3/9** 互通。A 技能节点 3 解锁上等、节点 7 解锁精制。是 B 类**唯一量源**，投喂按段位映射（红线④）。

### 2.2 稀有材料（🔴 C 独占 · 9 家族 × 6 品质 = 54）
由 `rareSubCatBySkill`（配置反推）确定每 C 技能的稀有家族：

| C 技能 | 稀有家族（subCat） | 喂给 B 技能 |
| --- | --- | --- |
| 访道 visiting | 朱砂 / 百年参 / 雪莲 | 丹鼎 |
| 结义 sworn | 精铁 / 玄铁 | 锻造 |
| 出使 envoy | 蚕丝 / 龙纹玉 / 犀角 / 南药 | 机巧 |

- 品质下界 `RARE_MIN_QUALITY=4`（item 表稀有只有 4–9 品）。
- 具体产出 = `${sub}_${q}`（如 `zhusha_5`），**不同品质=不同种类**，故跨品质比数量无意义。
- 掉率按 `rareSubCatWeightBySkill`（Plan C：由配方需求占比烘焙，使供给匹配需求）。

### 2.3 成品（B 产出）
35 制造族（V2 目标）× 9 品质展开。投喂铁律：n 品只吃 q≥n 料（红线④）。

### 2.4 名品（3 · 不可售 · 收藏类）
`mingqi_jade`(结义) / `mingqi_talisman`(访道) / `mingqi_exotic`(出使)。`sellable=false`，`price=0`。设计定位「成就物 / 外物线」，V5 扩展其「送礼换高价值好感 / 段3 托付钥匙」用途（**当前只堆积、用途未落地**）。

### 2.5 图纸（blueprint · 🔴 C 独占 · 一次性解锁进册）
- 不在背包，写入 `state.blueprints`，永久有效。
- 每 C 技能约 8 张（当前共 ~24），由 `blueprint.fromSkill` 绑定。
- 掉落：C 任务满足门槛时，从「该技能未拥有的图纸」中随机发一张（见 §四.4）。

## 三、制造系统（B 类）

### 3.1 配方结构（`RecipeDef`）

```
resultItem (成品) ← 基础层(needItem1 主料 + needRare 基础稀有)
                 ← 额外层(needItem2 他行当 q-1 料 + needRare2 他 C 技能 q-1 稀有)
                 ← 图纸门(needBlueprint，仅上品)
```

| 字段 | 含义 |
| --- | --- |
| `needItem1 / needItem1Num` | 基础层主料（配对 A 同阶料），**投喂下界** `matQualityFloor` 把关 |
| `needRare` | 基础层稀有（配对 C 同阶），q≥4 起 |
| `needItem2 / needItem2Num` | 额外层辅料（他 A 技能的 q-1 阶料） |
| `needRare2` | 额外层稀有（他 C 技能的 q-1 阶稀有） |
| `needBlueprint` | 图纸门 tag；q1–3 天生会 → 空 |

### 3.2 两层需求机制（关键修正）

| 层 | 性质 | 缺料处理 |
| --- | --- | --- |
| **基础层**（主料 + 基础稀有） | **开工门槛** | 不齐 → 停产（记 `starvedTasks`，不倒扣） |
| **额外层**（辅料 + 额外稀有） | **加成，非门槛** | 缺了不消耗、不停产；齐备时最多多产 `cycles × EXTRA_BONUS_RATIO` 件 |

> 旧实现四项齐备才开造，缺料率被两个稀有乘法叠加推到 ~51%；改为「基础层开工 + 额外层加成」后供给压力骤降。

### 3.3 图纸门（gate）

| 门槛 | 取值 | 说明 |
| --- | --- | --- |
| `BLUEPRINT_MIN_QUALITY` | **4** | V5 由 7 下移到 4（中段 q4 起制造就要图，否则长期无图可造） |
| `BLUEPRINT_MIN_EVAL_TIER` | 2（佳） | 评价门槛 |
| `BLUEPRINT_MIN_FAVOR` | 30 | 全局 `state.favor` 门槛（≠ 武将好感） |

> 任务板对高阶 B 任务显示「需要图纸 ✔ / 缺图(+缺料)」；基础档（q≤3）不显示图纸信息。

### 3.4 省料（评价 → 效率）
评价「绝」时材料消耗 −25%（`EFF_SAVE_AT_BEST=0.25`），按 `ev.mult` 线性缩放：`save = 0.25 × min(1, max(0, ev.mult-1))`。

### 3.5 缺料处理
- 材料不足 → `starvedMat`（红线⑦ 自动补货只补这一类）
- 稀有不足 → `starvedRare`（禁买，只能靠 C 产出）
- 均不倒扣玩家任何东西；库存不足按「能做几件做几件」交付。

## 四、C 类奖励机制（本次重点 · 对齐用户定案）

### 4.1 总原则（用户 2026-10-08 拍板）
1. **好感度 = 随机的稀有奖励**：生成时 10% 掷骰，不中则本次不给武将好感。
2. **更高档仅提供更具体产物 + 更多数量**：稀有料数量随**评价 4 档**递增（拙1/平2/佳3/绝4）；不同品质给不同稀有种类，跨品质比数量无意义。
3. **图纸 = 满足条件后较大概率出现的一次性奖励**：当前条件达成即 100% 掉落（比"较大概率"还高），天然一次性。

### 4.2 好感（武将关系）
- `C_FAVOR_CHANCE = 0.10`：生成时 `randFloat < 0.10` 才调 `pickFirstMeetHero` 锁 `heroTag`。
- `pickFirstMeetHero` 优先级：① 攻略对象 `target`（素未谋面）→ 定向攒 ② 素未谋面池随机 ③ 全池随机。
- 结算 `maybeFirstMeet(forcedTag=heroTag)`：素未谋面注入 `REL_FIRST_MEET=8` 并记初识日志；已结识则跳过初识、仍走 `propagateDeed` 给事迹传播好感。
- **旧档兼容**：无 `heroTag` 的任务仍走原 `REL_FIRST_MEET_CHANCE=0.35` 随机偶遇。
- 任务板：仅 heroTag 命中才显示「好感度」类别标签（不写具体武将名，结算前不知给谁）；不中则 C 卡无好感芯片。

### 4.3 稀有料
- 生成时 `pickRareTag`（q≥4）：用与结算**完全相同**的候选池+权重锁定 `rareTag`（所见即所得）。
- 结算优先用 `rareTag`；缺则走原池加权随机（旧档兼容）。
- **数量按评价档**：`rareCountByEval(tier) = tier+1` → 拙1 / 平2 / 佳3 / 绝4。
- 任务板显示区间 `稀有 朱砂 ×1~4`（生成时未知评价，避免定值误导）。

### 4.4 图纸（条件一次性）
掉落条件（`settleSocial`）：
```
q >= BLUEPRINT_MIN_QUALITY(4)
  && ev.tier >= BLUEPRINT_MIN_EVAL_TIER(2 佳)
  && state.favor >= BLUEPRINT_MIN_FAVOR(30)
  && 该 C 技能有「未拥有的图纸」
```
满足则从「未拥有池」随机发一张，`state.blueprints.push`（永久），记习得事件。条件全达即 100% 掉落。

> **任务板展示规则（正式）**：C 卡仅在「图纸门槛」静态部分（q≥4 ∧ favor≥30 ∧ 该技能有未拥有图）全部满足时显示「图纸」芯片（绿色 ok，表"有机会"）；评价≥佳属结算时判定，无法在板上预知，故芯片不承诺必得。门槛不满足（或该技能图纸已全部习得）则 C 卡不显示图纸芯片。该规则与 `settleSocial` 掉落门槛一致，根治此前"恒显裸标签、未达标仍显示"的误导。

### 4.5 名品（上品小概率）
```
q >= MINGQI_MIN_QUALITY(7) && ev.tier >= 2(佳) && randFloat < MINGQI_CHANCE(0.05)
```
按 `MINGQI_BY_C_SKILL` 发对应件（不可售收藏类）。

### 4.6 前期不进池
`C_MIN_QUALITY = 4`：q1–3 的 C 类不进随机池。根因——低品质 C 不产稀有（需 q≥4）、不产图纸（需 q≥4）、好感仅 10%，奖励空间被抽空，是前期信息噪点。过滤后前期 C 栏位自然稀疏，信息更聚焦。

### 4.7 任务板诚实化对照

| 现象 | 修正前 | 修正后 |
| --- | --- | --- |
| q<4 未命中好感的 C 卡 | 显示裸「好感」标签（误导必给） | 不显示好感芯片 |
| 所有 C 卡显示「稀有」裸标签 | q<4 不产稀有仍显示（误导） | 仅 rareTag 存在才显示具体料 |
| 图纸恒显（裸标签，未达标仍显示） | 未达标仍显、误导可产 | 改为条件显隐：q≥4 ∧ favor≥30 ∧ 该技能有未拥有图 才显示（评价≥佳为结算判定，仅表"有机会"） |

## 五、三线咬合闭环 + 红线

```
A 采集（3技能）──材料(量)────┐（够不够）
                            ├──→ B 制造（3技能）──→ 兵器/消耗品/跑商道具
C 人物（3技能）──图纸+稀有(质)┘（能不能造/造多好）
```

| # | 红线 / 铁律 | 保证 |
| --- | --- | --- |
| ① | 稀有只有 C 给 | A 供量、C 供质不被破 |
| ② | 图纸只有 C 给 | C 是 B 前置不可跳过 |
| ③ | 高阶配方 = 图纸城 + 材料A城 + 材料B城 三城互异 | 强制跨城 |
| ④ | n 品制造只吃 q≥n 料 | 高品 A 料档位投入不被平替 |

> 同品咬合：`n 品 B 制造 = n 品 A 料(量) + n 品 C 稀有(质)` → A/B/C 三线共升到 n。C 的中/上品才开稀有与图纸门 → 「练 C 到中品」是制造高阶的硬前置。
